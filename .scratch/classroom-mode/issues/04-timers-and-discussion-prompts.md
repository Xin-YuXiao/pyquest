# 04: 作答倒计时与同伴讨论计时

Status: needs-info
Type: task
Blocked by: 01, 03

## 要做什么

每题可设置作答倒计时（题单级默认值 + 单题覆盖，默认值取 01 号工单结论）；讨论阶段有独立计时器与提示语
（「和邻座比较你的答案，试着说服对方」）。倒计时显示大号数字，结束时轻提示（视觉闪一下 + 可选一声短音效，静音时只有视觉）；
计时可暂停/继续/加 30 秒，全部可用键盘与翻页器操作。

## 验收标准

- [ ] 题单级默认计时与单题覆盖都能保存并在下次载入后生效
- [ ] 倒计时暂停/继续/加时正确；结束提示在 prefers-reduced-motion 下降级为静态提示
- [ ] 计时器不影响计票（倒计时结束后仍可继续录票）
- [ ] E2E 用固定的短计时（或测试接缝的时间推进语义动作）验证结束提示出现，不依赖真实长等待
- [ ] `npm run check` 全绿
