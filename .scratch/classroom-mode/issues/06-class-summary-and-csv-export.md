# 06: 课后汇总与 CSV 导出

Status: needs-info
Type: task
Blocked by: 01, 03

## 要做什么

每节课结束（或中途退出）生成课堂汇总：每题的章节标签、题 id、正确选项、第一轮/第二轮各选项人数与正确率、提升幅度、是否触发护盾；
汇总页可打印（打印样式）并一键导出 CSV（UTF-8 BOM，Excel 打开中文不乱码，字段与 01 号工单一致，约定与 learning-report 的 CSV 对齐）。
最近 N 节课的汇总保存在课堂存储里（N 取 01 号工单结论），可在课堂模式首页查看历史并删除。不保存任何学生身份信息。

## 验收标准

- [ ] 汇总表数值与各题录入的票数一致（含跳过第二轮的题）
- [ ] 导出 CSV 用 Playwright 下载事件捕获，表头与行数正确、带 BOM
- [ ] 历史汇总超出上限时提示导出后清理；删除单节课历史需确认
- [ ] 打印预览中只出现汇总表（无按钮、无投屏装饰）
- [ ] `e2e-classroom` 增加汇总与导出断言
- [ ] `npm run check` 全绿
