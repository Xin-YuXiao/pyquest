# 07: 从教师题包选题

Status: needs-info
Type: task
Blocked by: 02

## 要做什么

课堂模式的选题界面增加「教师题包」来源：只读列出 custom-quiz-packs 已导入的题包（标题、作者、题数），可从题包里勾选题目加入课堂题单，
与主线题池的题混排。题包题目一律按纯文本/转义渲染（沿用 custom-quiz-packs 的安全约定）。

依赖说明：需要 custom-quiz-packs 的「导入与练习场」工单（其 02 号）先落地并提供题包存储的只读访问；在那之前本工单保持 needs-info。

## 验收标准

- [ ] 已导入题包出现在选题来源里；题包题目可加入题单、投屏、计票、导出（导出时题 id 带 `pack:<id>` 前缀以区分来源）
- [ ] 删除题包后，引用它的已保存题单在载入时提示「n 道题来源已不存在」并自动剔除
- [ ] 含 `<script>` / `<img onerror>` 的恶意题包内容在投屏中按字面显示、不执行（E2E 用全局标志检测）
- [ ] `npm run check` 全绿
