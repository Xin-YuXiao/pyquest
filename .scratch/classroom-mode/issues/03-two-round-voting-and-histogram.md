# 03: Peer Instruction 两轮计票、分布直方图与揭晓对比

Status: needs-info
Type: task
Blocked by: 01, 02

## 要做什么

在投屏流程里加入两轮计票：第一轮录入各选项人数 → 显示分布直方图（不揭晓答案）→ 根据第一轮正确率显示流程建议 →
（讨论）→ 第二轮录入 → 揭晓正确项（高亮）+ 解析 + 两轮对比「x% → y%」。单题可跳过第二轮直接揭晓。

- 录票：大按钮点击 +1、右键/长按 −1；键盘 1-4 与 A-D 为对应选项 +1，Shift+键 −1；点击人数可直接输入；清零需确认；显示合计人数与（可选）应到人数的参与率。
- 统计纯函数：`distribution`、`correctRate`、`advice`、`gain`，阈值取 01 号工单结论，放入数据层并测试。
- 「上一步」不清除已录入票数；揭晓前任何界面元素（颜色、排序、动画）都不能泄露正确项。
- 直方图每根柱子标字母与人数/百分比，不只靠颜色区分；揭晓后正确项柱子用纹理/图标标记。
- 01 号工单若决定支持「只录对/错两类」的简化模式，在本工单一并实现为题单级开关。

## 验收标准

- [ ] 第一轮录入后直方图百分比正确，且揭晓前 DOM 中不存在可见的正确项标记
- [ ] 流程建议按 01 号工单阈值显示（边界值各有测试）
- [ ] 第二轮后揭晓正确项与解析，「x% → y%」数值正确；跳过第二轮时只显示第一轮
- [ ] 键盘与鼠标两种录票方式结果一致；「上一步」不丢票
- [ ] 数据层测试覆盖：0 票、全票集中一个选项、只有一轮、阈值边界
- [ ] `e2e-classroom` 增加两轮计票与跳过第二轮两条路径
- [ ] `npm run check` 全绿
