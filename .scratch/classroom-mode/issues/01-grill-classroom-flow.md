# 01: 拍板：课堂流程、默认参数与 BOSS 战规则

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

与助教一起敲定课堂模式里所有「教学判断」类参数，结果追加到本文件 `## Answer` 并回写 spec 的「待决策」：

- Peer Instruction 建议阈值：先核实 Crouch & Mazur (2001) 原文与 Mazur 课堂指引中的经验区间，再定默认值（spec 推荐 30% / 70%）及界面说明措辞；
- 默认是否两轮、单题能否跳过第二轮、是否提供「只录对/错两类」的举手简化模式；
- 默认作答倒计时与讨论计时（或默认关闭计时）；
- 全班 BOSS 战：伤害换算（线性？）、护盾阈值与折扣、题单答完未击败时的文案；
- 课后统计保留节数、CSV 字段清单；
- 投屏选项标签：A/B/C/D 与 1/2/3/4 并列，还是只用一种。
