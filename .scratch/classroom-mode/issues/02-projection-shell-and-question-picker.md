# 02: 课堂模式外壳：入口、选题、一题一屏投屏与翻页器操作

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

助教在标题画面点「课堂模式」→ 进入全视口投屏层 → 按章节/题池浏览题目（题面摘要、是否带代码）→
勾选或「从题池随机抽 N 题」组成题单（可命名保存到课堂存储、下次载入）→ 开始 → 一题一屏投影：
超大字号题面、高亮代码块、选项标 A/B/C/D 与 1/2/3/4；←/→/PageUp/PageDown/空格翻页，F 全屏，B 黑屏，Esc 退出（确认后回标题画面）。

本工单不含计票与 BOSS 战（03/05），只把「选题 → 投屏 → 翻页 → 退出」跑通，并建立课堂存储键与测试接缝。

- 投屏层覆盖整个视口（不放进 960×640 的设计坐标系），16:9 与 4:3 下排版均不溢出；长代码块可滚动且不折行错乱。
- 投屏前确认答题行为层的语法高亮已修复字符串字面量嵌套标签缺陷（见 custom-quiz-packs 01 号工单）；若尚未修复，本工单内按其方案修复并补数据层测试。
- 全程不读写玩家存档键、不调用任何游戏状态变更函数。

## 验收标准

- [ ] 标题画面出现「课堂模式」按钮；进入后不创建任何野外/巢穴场景
- [ ] 可按章节→题池浏览全部 34 个题池的题目；勾选、随机抽 N 题、保存/载入题单均可用，刷新后题单仍在
- [ ] 投屏显示题面、高亮代码、A/B/C/D + 1/2/3/4 选项；1280×720、1920×1080、1024×768 三种视口截图无溢出
- [ ] ←/→/PageUp/PageDown/空格 翻页，F 全屏（Fullscreen API 不可用时静默忽略），B 黑屏切换，Esc 确认后回到标题画面
- [ ] 测试接缝新增只读 `classroom()`（阶段、题单、当前题 id）与语义动作 `clearClassroomStore()`
- [ ] 新增非章节 E2E 套件 `e2e-classroom` 覆盖上述流程并登记进 `npm run test:e2e`；断言退出后玩家存档键不存在
- [ ] 高亮输出结构良好（数据层测试：含字符串字面量的代码高亮后不出现嵌套在属性里的标签）
- [ ] `npm run check` 全绿
