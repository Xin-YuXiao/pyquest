# 05: 全班 BOSS 战

Status: needs-info
Type: task
Blocked by: 01, 03

## 要做什么

课堂题单可选「全班 BOSS 战」包装：开场选择一个章节 BOSS（名字取章节注册表的 bossName），投屏显示 BOSS 形象与血条；
每题揭晓后按全班最终正确率（有第二轮取第二轮）对 BOSS 造成伤害并播放受击反馈；正确率低于护盾阈值时显示「BOSS 护盾：这题需要讲解」并打折伤害；
题单结束时结算页显示击败/剩余血量与每题伤害条形图。全程只有全班数字，没有个人分数与排行榜。

- BOSS 形象：优先复用游戏已加载的贴图（课堂模式在 BootScene 完成后进入，从纹理管理器取帧绘制；需核实可行性），不可行则用程序化像素图标；不依赖 Tiny Swords 原始素材是否存在（占位素材环境下也不报错）。
- 伤害换算 `bossDamage(rate, config)` 为纯函数，规则取 01 号工单结论。
- 受击动画尊重 prefers-reduced-motion。

## 验收标准

- [ ] 选 BOSS → 血条 → 每题按正确率扣血 → 结算页，数值与 `bossDamage` 一致
- [ ] 低正确率出现护盾提示且伤害打折；全部题答完未击败时显示 01 号工单定下的鼓励文案
- [ ] 页面任何位置都不出现个人得分/排名
- [ ] 占位素材（gen-ts-stubs）环境下 BOSS 形象正常显示或优雅降级，浏览器无报错
- [ ] 数据层测试覆盖伤害换算边界（0%、100%、阈值两侧）；`e2e-classroom` 增加 BOSS 战路径
- [ ] `npm run check` 全绿
