Status: resolved
Type: task
Blocked by: 02, 03

## 要做什么

- 数据史莱姆王「索引帮手」：帮手头顶标 `[0] [1] [2]`，王点名 `list[i]`（含负索引），打中被点名帮手 → 王护甲掉一层；打错 → 王再 `append` 一只帮手（帮手总数设上限，避免刷屏）。
- 混沌曲线魔君「广播弹幕」：一行 + 一列弹幕预警成 N×N 网格，掩膜点亮的格子安全；预警 0.8 秒，减少动态效果模式下预警时长加倍、取消闪烁。
- 迟缓巨魔「迟缓光环 + @jit 加速」：光环内玩家移速减半；破盾瞬间获得限时加速 buff，HUD 显示倒计时。

点名索引、安全格掩膜用按章 seed 派生的伪随机，保证 E2E 可复现。

## 验收标准

- [ ] 三章章节注册表改用对象写法声明机制

- [ ] 第一章机制对初学者宽容：打错不扣心（与 grilling 结论一致）
