# 04: 二阶段：护盾再生与第二块 BOSS 符文（先在样板 BOSS 上启用）

Status: needs-info
Type: task
Blocked by: 02, 03

## 要做什么

- 章节配置 `phase2: { atHp }` 启用后，巢穴额外放置一块初始隐藏的第二 BOSS 符文槽 `c{N}boss2`，映射到本章 boss 题池（与第一块同池不撞题）。
- BOSS hp 降到 `atHp`：若 `c{N}boss2` 已在已答槽位中 → 不再上盾（「已领悟的咒语不会被遗忘」）；否则护盾重生（与初始护盾同样的免伤与浮字）、第二块符文显形并可交互。
- 答对第二块符文 → 护盾破碎，战斗继续；答错按现有规则扣心（最低留 1 心）。
- 死亡重生 / 离开巢穴再回来：BOSS 满血重来，二阶段按上面的规则重新判定，不会出现「符文已灰但护盾还在」的卡关。
- 先在第七章样板上启用，其余章节按 grilling 结论在铺开工单里开启。

## 验收标准

- [ ] smoke：启用二阶段的章节，`c{N}boss2` 在题池映射里且指向本章 boss 池；未启用的章节没有该槽位
- [ ] 第七章 E2E 新增 `bossPhase2` 步骤：hp 到阈值 → 断言护盾重生 → 用真实答题助手答第二块符文 → 断言破盾 → 击败通关
- [ ] 新增 E2E 场景：答对第二块符文后让玩家死亡重生，再进巢穴把 BOSS 打到阈值，断言护盾不再重生
- [ ] 跳章接缝 `gotoChapter` 仍把前序章节完整标记通关（含第二块符文槽），读档续玩不受影响
- [ ] `npm run check` 全绿
