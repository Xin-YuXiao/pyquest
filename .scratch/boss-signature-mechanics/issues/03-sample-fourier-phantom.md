# 03: 样板：傅里叶魅影「频率分身」（第七章）

Status: needs-info
Type: task
Blocked by: 01, 02

## 要做什么

在第七章跑通「配置 → 机制模块 → 原型钩子 → 接缝 → E2E」全链路：

- 傅里叶魅影破盾后 hp 降到阈值（缺省 7）时分裂成三个分身：各自按不同频率闪烁（低/中/高），头顶标 1 / 4 / 7 Hz；本体隐去且免伤。
- 玩家须按频率从低到高击破分身；击破正确的分身在头顶打勾；顺序错 → 三个分身重组（「逆变换」）、本体回 1 hp、浮字解释「先击破最低频率的分身」。
- 三个分身全部击破 → 本体「ifft 还原」现形并硬直 2 秒，之后恢复正常战斗直至击败。
- 系统开启「减少动态效果」时，闪烁降级为静态的频率数字标签。
- `pinBoss` 冻结时分身停在原位、闪烁停止；`bossInfo.targets` 返回三个分身的频率标签、坐标、是否已击破。
- 顺序判定写成纯函数，smoke 用固定输入覆盖（正确顺序、各种错误顺序、重复击打同一分身）。
