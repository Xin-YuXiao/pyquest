# 星系分类台：先当分类员，再训练分类器

Status: needs-triage
Priority: P2
Source: 接手评估新增 · 借鉴教学研究/教育产品（见 .scratch/INSPIRATION.md）——Galaxy Zoo 课堂实践（真实数据、人人可参与的科学分类）
Depends on: observatory-minigames（复用其「小游戏宿主」与观测台道具）；quiz-expansion-w4-w8 的 01 号素材工单（若采用课程 Project-5/7 的数据）；可选协同 learning-records（记录完成情况）

## 问题陈述

- **学生视角**：W7 考了混淆矩阵（sg18：行=真实、列=预测），W11 考了类别不平衡的 99% 陷阱（pj16）和机器学习流程链（pj6/pj7），
  课程 Project-5（ResNet 星系形态分类）、Project-7（光谱分类）要求真正训练分类器——但在游戏里这些都只是四选一，
  学生从没「亲手」体会过：分类本身就有主观分歧、准确率会骗人、特征选得好坏决定一切。
- **天文视角**：Galaxy Zoo 证明了「普通人给星系分类」既是真科学又很有吸引力；导论天文课的做法是让学生先分类一小批星系，再和志愿者/专家结果对比。
  这正好是混淆矩阵最直观的入门：先给「自己」画一张混淆矩阵。
- **助教视角**：需要一个 10 分钟内能玩完、能在课上投屏演示的 ML 直观实验，衔接 W7 sklearn 与 Project-5/7。
- **风险**：真实星系图像的使用许可与体积未知；不能在没核实许可前把外部图像打进仓库或构建。

## 解决方案

一座「星系分类台」（观测台的一种，可选、不阻塞主线），两关：

1. **第一关：你是分类员。** 屏幕依次出现一批星系图（v1 为程序生成的「卡通星系」：椭圆 / 旋涡 / 并合等），
   玩家给每个星系点选类别（可选「不确定」）。结束后显示：玩家的准确率、玩家 vs 专家标签的**混淆矩阵**（行=真实、列=玩家判断，与 sg18 同约定）、
   以及「专家之间也有分歧」的样例（标签本身带不确定度的星系）。
2. **第二关：训练分类器。** 每个星系有几项可测特征（颜色、光度集中度、轴比、旋臂强度、双核标志）。玩家：
   - 选 1–2 个特征，看训练集在特征平面上的散点（按真实类别着色）；
   - 选分类器：**决策树桩**（拖动阈值线）或 **k 近邻**（选 k）；
   - 在留出的测试集上看准确率与混淆矩阵；
   - 挑战关「稀有并合星系」：并合只占 2%，「全部预测为多数类」的哑模型也有 98% 准确率——必须看混淆矩阵与每类召回率才能识破（呼应 pj16）。
3. 完成判定与星级由宿主统一记录；首次完成给温和奖励（与观测台一致）。

## 用户故事

1. 作为学生，我想要亲手给 20 个星系分类，以便体验天文学家（和 Galaxy Zoo 志愿者）真正在做的事。
2. 作为学生，我想要分类时可以选「不确定」，以便诚实地表达模糊情况，而不是被迫乱猜。
3. 作为学生，我想要看到自己 vs 专家标签的混淆矩阵，以便第一次「从内部」理解行=真实、列=预测的含义。
4. 作为学生，我想要点开混淆矩阵的某一格看到对应的星系，以便知道自己在哪类上犯错。
5. 作为学生，我想要看到专家标签本身也有不确定度的例子，以便理解「真值」在天文里也可能是统计意义上的。
6. 作为学生，我想要在第二关选择特征并看到特征平面上的散点，以便直观理解「特征能不能把类别分开」。
7. 作为学生，我想要拖动决策树桩的阈值并实时看到准确率变化，以便理解分类边界是怎么来的。
8. 作为学生，我想要切换到 k 近邻并调整 k，以便比较不同分类器的行为。
9. 作为学生，我想要模型只在留出的测试集上评分，以便记住「在训练集上评估是自欺欺人」（呼应 pj7）。
10. 作为学生，我想要在稀有类挑战中看到 98% 准确率的哑模型被混淆矩阵当场拆穿，以便永远记住准确率会骗人（pj16）。
11. 作为学生，我想要看到每类的召回率，以便知道「找全稀有类」需要什么指标。
12. 作为学生，我想要两关都能在 10 分钟内完成，以便不打断主线节奏。
13. 作为学生，我想要分类台可以随时退出且不丢主线进度，以便放心尝试。
14. 作为学生，我想要再次进入时换一批星系（不同种子），以便重复练习不是背答案。
15. 作为助教，我想要在课上投屏演示第二关的「阈值拖动」，以便讲解分类边界与混淆矩阵。
16. 作为助教，我想要分类台的讲解用词和 W7/W11 的题目一致（混淆矩阵、召回、train/test），以便和课堂衔接。
17. 作为助教，我想要（许可允许时）换成真实的星系图像，以便学生接触真实数据。
18. 作为色弱学生，我想要散点和矩阵不只靠颜色区分类别（形状/字母标注），以便读懂图表。
19. 作为触屏用户，我想要点选分类按钮与拖动阈值在手机上可用，以便在平板上玩。
20. 作为维护者，我想要星系生成、特征计算、分类器、混淆矩阵都是带种子的纯函数，以便数据层测试锁定结果。
21. 作为维护者，我想要外部图像只有在许可核实后才进入构建，以便不重蹈 Tiny Swords 的许可问题。
22. 作为维护者，我想要分类台复用观测台宿主，以便不重复写弹层、暂停、记录与焦点管理。

## 实现决策

- **宿主**：作为观测台小游戏之一，实现 observatory-minigames 约定的小游戏接口
  `{ id, chapter, title, intro, generate(seed), mount(container, data, report), judge(data, result) }`；
  两关为同一小游戏的两个阶段，或注册为两个小游戏（01/02 号工单定）。入口章节待 02 号决定（推荐第七章通关后，衔接 sklearn 与混淆矩阵）。
- **程序化「卡通星系」**（v1 数据源，不依赖外部数据）：`generateGalaxy(seed, class)` 输出参数
  （类别、颜色指数代理、光度集中度、轴比、旋臂数与强度、是否双核/潮汐尾、噪声水平、标签置信度），
  并在 canvas 上渲染成小图（椭圆=平滑椭圆光斑；旋涡=盘 + 对数螺旋臂；并合=双核 + 潮汐尾；可选不规则）。
  标签置信度 < 1 的星系是「专家也分歧」样例。
- **特征**：v1 由生成参数加测量噪声得到（明确告诉玩家这是「测量值」）；「从像素直接测量」列为后续。
- **分类器（纯 JS）**：决策树桩（单特征阈值，阈值可由玩家拖动或一键「自动找最优」）、k 近邻（欧氏距离、特征先标准化、k 可选奇数）；
  基线「全部预测为多数类」用于稀有类挑战。训练/测试按固定种子划分（呼应 pj15 的 random_state 可复现）。
- **评估**：混淆矩阵（行=真实、列=预测，与 sg18 同约定）、总准确率、每类召回率；矩阵格子可点击查看对应样本。
- **判定**（交给宿主）：第一关完成即算完成，星级按与专家一致率；第二关在稀有类挑战中要求「稀有类召回率 ≥ 阈值」而不是总准确率（阈值 02 号定）。
- **真实数据（可选，06 号）**：许可核实通过后，用一小批（建议 ≤ 50 张、64–96px 缩略图、总量 ≤ 300KB）真实星系图 + 公开分类标签替换第一关数据；
  特征改用公开目录里的测量值。数据与许可声明一起入库或构建期下载（01 号决定）。
- **可访问性**：类别用形状 + 字母 + 颜色三重编码；阈值滑块支持键盘方向键；尊重 prefers-reduced-motion。
- **测试接缝**：沿用观测台的只读 `observatoryInfo()`，扩展字段：当前关卡、种子、玩家分类结果、分类器参数、测试集指标。

## 测试决策

- **好测试的标准**：断言玩家能看到的数字与判定（混淆矩阵各格、准确率、召回率、完成/星级），不断言渲染细节。
- **数据层（smoke）**：
  - 生成器确定性（同种子同参数）；各类别在主特征上的统计可分性（例如旋涡的旋臂强度均值显著高于椭圆），防止生成器回归成「不可分」；
  - 混淆矩阵与准确率/召回率在手算小样例上正确（含某类 0 样本的边界）；
  - 稀有类挑战：哑模型准确率 = 多数类占比，稀有类召回率 = 0；
  - 决策树桩「自动找最优」在可分样例上达到 100%，k 近邻在训练点上 k=1 时训练准确率 100%。
- **E2E**：独立套件（或观测台套件的一条路径）：传送到分类台 → 第一关用测试接缝读专家标签后真实点击分类 → 断言混淆矩阵对角线 →
  第二关选特征与分类器、拖动阈值（键盘）→ 稀有类挑战：先提交哑模型断言「未通过」与召回率 0，再提交合理阈值断言通过 → 完成记录写入。
- **先例**：observatory-minigames 的宿主与 NFW 拟合样板测试；runner 的「浏览器无报错」与外网拦截。

## 待决策

1. **类别体系**：推荐 v1 三类「椭圆 / 旋涡 / 并合」（并合同时承担稀有类挑战）；Galaxy Zoo 的「平滑 / 有结构 / 星点或伪影」更贴近真实项目但对新手抽象——列为真实数据阶段再议。
2. **入口章节**：推荐第七章（通关后开放，衔接 sklearn fit/predict 与混淆矩阵 sg18）；备选第十一章（ML 流程链）。
3. **两关是一个小游戏还是两个**：推荐一个小游戏两阶段（共享数据与种子，玩家理解连贯）。
4. **稀有类挑战的通过标准**：推荐「稀有类召回率 ≥ 0.6 且总准确率 ≥ 0.9」，强调不能只看一个指标。
5. **真实数据来源**：待 01 号核实（候选：Galaxy Zoo 公开分类目录 + SDSS / Legacy Surveys 缩略图；课程 Project-5 使用的数据集）；推荐只有在许可明确允许再分发时才入库。

- 不新增四选一题目（ADR-0001）；分类台里的讲解文字只复用 sg18、pj7、pj15、pj16 等已有题目的知识点，并在代码注释中注明题 id。
