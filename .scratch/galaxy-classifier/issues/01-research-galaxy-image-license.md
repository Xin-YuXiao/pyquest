# 01: 核实真实星系图像与分类标签的许可与体积

Status: ready-for-human
Type: research
Blocked by: None (can start immediately)

## 要做什么

在任何外部图像进入仓库或构建之前，人工核实候选数据源的使用条款并给出推荐方案，结论追加到 `## Answer`：

- 候选：Galaxy Zoo 公开分类目录（标签/投票比例）、SDSS 图像（cutout 服务）、DESI Legacy Imaging Surveys 缩略图、课程 Project-5 / Project-7 实际使用的数据集（需对照课程素材，见 quiz-expansion-w4-w8 的 01 号素材工单）；
- 每个来源：是否允许再分发（入库 / 打进公开部署的构建）、署名要求、是否允许修改（裁剪、缩放、压缩）；
- 体积预算：建议 ≤ 50 张、64–96px、总量 ≤ 300KB；给出实际可选样本的类别分布；
- 结论之一：入库（附许可文件与署名）/ 构建期下载 / 不用真实数据（只保留程序化星系）。

## 验收标准

- [ ] 每个候选来源都有许可原文链接、关键条款摘录与「能否再分发」结论
- [ ] 给出推荐方案与理由；若推荐入库，列出署名文本与放置位置
- [ ] 结论回写 spec「待决策」第 5 条
