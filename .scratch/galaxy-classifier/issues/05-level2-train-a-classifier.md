## 要做什么

第二关界面：特征选择（1–2 个）→ 训练集特征平面散点（按真实类别形状/颜色编码）→ 选分类器（决策树桩可拖阈值线 / k 近邻选 k / 多数类基线）→
测试集准确率、每类召回率、混淆矩阵实时更新。最后是稀有类挑战：并合星系占 2%，玩家提交模型，判定按 02 号结论（稀有类召回 + 总准确率），
提交哑模型时明确显示「准确率 98% 但一个并合都没找到」。

## 验收标准

- [ ] 阈值线可用鼠标拖、触屏拖、键盘方向键微调；指标随之实时更新且与纯函数核心结果一致
- [ ] 只在测试集上评分，界面明确标注「测试集」
- [ ] 稀有类挑战：哑模型被判「未通过」并显示召回率 0；合理模型可通过
- [ ] 讲解文字只使用 sg18 / pj7 / pj15 / pj16 已有知识点的术语，代码注释标明题 id
- [ ] E2E：选特征 → 键盘调阈值 → 先提交基线断言未通过 → 再提交合理阈值断言通过
- [ ] `npm run check` 全绿
