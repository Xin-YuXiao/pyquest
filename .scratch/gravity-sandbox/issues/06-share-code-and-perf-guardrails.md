# 06: 场景分享码与性能护栏

Status: ready-for-agent
Type: task
Blocked by: 03

## 要做什么

- 分享码：沙盒里「复制场景」生成分享码、「粘贴场景」载入；非法/过长输入友好报错不崩溃；
- 性能护栏：固定每帧最多子步数，帧时间超预算时自动降低渲染频率而不改变物理步长（保持确定性）；页面切后台时暂停模拟；
- 移动端：双指缩放/拖拽平移不与放置手势冲突（放置需短按，拖拽速度需从天体上开始）。

## 验收标准

- [ ] 分享码往返后场景完全一致（E2E：复制 → 重置 → 粘贴 → 读接缝状态比对）
- [ ] 非法分享码显示错误提示，状态不变
- [ ] 切后台后模拟时间不前进
- [ ] 移动视口（hasTouch）下放置、拖速度、缩放各自可用（E2E 一条触屏路径）
- [ ] `npm run check` 全绿
