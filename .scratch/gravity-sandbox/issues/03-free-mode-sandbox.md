# 03: 自由模式沙盒：放置、拖拽初速度、轨迹与能量曲线

Status: resolved
Type: task
Blocked by: 01, 02

## 要做什么

在 01 号决定的章节观测台里打开引力沙盒（复用观测台宿主）：点击放置天体、拖拽拉出初速度箭头、空格开始/暂停、`.` 单步、R 重置到摆放状态；
轨迹拖尾；侧边能量曲线 + 数值读数；滚轮/双指缩放与拖拽平移；天体数量上限与提示。物理按固定子步推进，渲染插值显示。

依赖说明：需要 observatory-minigames 的宿主（其 02 号工单）已落地。

## 验收标准

- [ ] 鼠标、触屏、键盘三种方式都能完成放置与设定初速度
- [ ] 能量读数与核心 `energy()` 一致；暂停/单步/重置行为正确
- [ ] 达到天体上限时不能继续放置并有提示
- [ ] prefers-reduced-motion 下拖尾与闪光降级
- [ ] 测试接缝扩展 `observatoryInfo()`（场景、t、总能量）与语义动作 `sandboxStep(n)`
- [ ] E2E：真实指针拖拽放置卫星 → `sandboxStep` 推进 → 断言轨迹与能量读数出现、浏览器无报错
- [ ] `npm run check` 全绿
