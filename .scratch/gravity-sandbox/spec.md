# 引力沙盒：亲手摆一个 N-body 系统

Status: needs-triage
Priority: P2
Source: 接手评估新增 · 借鉴教学研究/教育产品（见 .scratch/INSPIRATION.md）——Universe Sandbox 的课堂用法（学生用模拟产生虚拟数据支撑论证）
Depends on: observatory-minigames（复用小游戏宿主与观测台道具）；可选协同 mobile-touch-controls（触屏拖拽手感）、accessibility（减少动态效果）

## 问题陈述

- **学生视角**：W6 巢穴考了 N-body 的三个关键技巧——softening 防发散（nm20：g(r)=1/(r²+ε²)，ε=0.5 时 g(0)=4.0）、
  成对求和用 np.triu 只数 i<j（nm19）、广播一行算出全部两两位置差（nm6），W8 考了「暗物质粒子只受引力」（dm4）。
  但这些都是读代码选答案；学生没见过 softening=0 时两颗粒子擦肩而过「飞出宇宙」的样子，也没见过步长太大时轨道一圈圈外扩。
- **天文视角**：引力系统的直觉（圆轨道需要多大速度、三体为什么不稳定、积分误差怎么表现为能量漂移）最好的老师是「自己摆一个试试」。
  Universe Sandbox 一类工具在课堂上被用来让学生做数字实验、产生证据；PyQuest 里已经有观测台框架，可以做一个轻量版本。
- **助教视角**：需要一个可投屏的演示：拖动 softening 滑块，现场展示「发散 ↔ 稳定」，衔接 W6 讲义的 N-body 示例。

## 解决方案

一座「引力沙盒」观测台（可选、不阻塞主线）：

1. **自由模式**：在星空画布上点击放置质点、拖拽拉出初速度（弹弓式，箭头显示速度），按空格开始/暂停；轨迹拖尾；
   侧边实时曲线显示**总能量**（动能 + 势能）随时间的变化——能量线平稳说明模拟可信，漂移说明步长/近距离问题。
2. **破坏实验**：两个滑块「时间步长」「softening ε」，配合预设场景（两颗粒子近距离擦肩、一颗行星绕恒星）：
   把 ε 拖到 0 → 擦肩时速度爆表、粒子飞出、能量曲线断崖；把步长拖大 → 圆轨道变成外扩螺旋。讲解文字只引用 nm20 / nm19 / nm6 / dm4 已有知识点。
3. **挑战关卡**（玩法类，具体数值待 01 号确认）：
   - 「三圈不坠毁」：给中心恒星，摆一颗卫星让它绕行 3 圈不撞、不逃逸；
   - 「三体十秒」：摆三个等质量天体，让系统 10 秒（模拟时间）内不散架；
   - 「最省燃料入轨」：探测器有若干次喷射机会，用最少的速度增量进入目标环带。
   每关有完成判定与星级，个人最佳（不做排行榜）。

## 用户故事

1. 作为学生，我想要点击放置天体、拖拽设定初速度，以便几秒钟就摆出一个自己的引力系统。
2. 作为学生，我想要看到天体的轨迹拖尾，以便看清轨道形状。
3. 作为学生，我想要随时暂停、单步、重置到摆放时的状态，以便反复试验。
4. 作为学生，我想要看到总能量随时间的曲线，以便判断模拟是否可信。
5. 作为学生，我想要把 softening 拖到 0 时亲眼看到近距离擦肩导致的「飞出宇宙」和能量断崖，以便真正理解 nm20 里那个 ε 的作用。
6. 作为学生，我想要把步长调大时看到圆轨道变成外扩螺旋，以便理解「步长」不是随便取的。
7. 作为学生，我想要讲解里提到「成对求和只数 i<j」并能切换显示「本帧计算了多少对」，以便把 nm19 的 np.triu 和眼前的模拟联系起来。
8. 作为学生，我想要挑战「三圈不坠毁」，以便在试错中找到圆轨道所需的速度感觉。
9. 作为学生，我想要挑战「三体十秒」，以便体会多体系统的混沌与不稳定。
10. 作为学生，我想要挑战「最省燃料入轨」，以便理解喷射时机比喷射大小更重要。
11. 作为学生，我想要每关有完成判定、星级与个人最佳，以便有动力优化方案。
12. 作为学生，我想要挑战失败时看到原因（撞上了 / 逃逸了 / 超时），以便知道怎么改。
13. 作为学生，我想要沙盒可以随时退出且不影响主线，以便放心探索。
14. 作为触屏用户，我想要用手指拖出初速度、双指缩放视野，以便在平板上玩。
15. 作为助教，我想要在投屏时现场拖动 softening 滑块演示发散与稳定，以便衔接 W6 的 N-body 示例。
16. 作为助教，我想要一个「复制当前场景」的分享码，以便把我摆好的演示场景发给学生。
17. 作为助教，我想要沙盒的讲解文本只用课上讲过的概念，以便不和讲义冲突。
18. 作为维护者，我想要积分器、能量计算、挑战判定都是固定步长、带种子的纯函数，以便同一输入在任何机器上得到同一结果，E2E 可断言。
19. 作为维护者，我想要天体数量有上限、渲染与物理解耦，以便低端设备不卡顿。
20. 作为维护者，我想要沙盒复用观测台宿主，以便不重复写弹层、暂停与完成记录。
21. 作为偏好减少动态效果的玩家，我想要拖尾与爆炸效果可以降级，以便不眩晕。

## 实现决策

- **宿主**：实现 observatory-minigames 的小游戏接口；入口章节待 01 号决定（推荐第六章通关后，衔接 nm19/nm20/nm6；备选第八章，衔接 dm4）。
- **物理核心（纯函数）**：
  - 状态：`{ bodies: [{ x, y, vx, vy, m, fixed? }], t }`；二维、无量纲单位（G=1）；
  - 加速度：两两求和只遍历 i<j 并对两者各加一次（与 nm19「每一对只数一次」一致），力律带 softening：
    加速度大小按 m/(r²+ε²) 计（与 nm20 的 g(r)=1/(r²+ε²) 同式）；
  - 积分：固定时间步长的辛积分器（推荐蛙跳 / kick-drift-kick，长期能量不漂移）。**界面不出现积分器名称**，只出现「时间步长」——
    讲义是否讲过具体积分方法需核实（01 号）；若讲过，再按讲义术语补充说明；
  - 能量：动能 + 势能（成对势能与上面的软化力律一致的软化势，i<j 求和）；
  - 渲染与物理解耦：物理按固定步长推进（每帧若干子步），渲染只插值显示，保证确定性。
- **规模与性能**：自由模式天体上限（推荐 30，O(N²) 每帧最多 435 对，足够流畅）；超过上限时禁止继续放置并提示；预设场景 ≤ 10 个天体。
- **挑战判定（纯函数）**：
  - 三圈不坠毁：累计绕中心转角 ≥ 3×2π 且期间与中心距离始终在 (r_min, r_max) 内；
  - 三体十秒：模拟时间 10 单位内任意两体距离不超过 R_escape 且无碰撞；
  - 最省燃料：进入目标环带并稳定 1 圈，Δv 总和越小星级越高。
  具体阈值与单位换算由 01 号确认后写成关卡数据。
- **交互**：点击放置（质量由当前选择的「天体类型」决定）、拖拽拉出速度箭头（长度∝速度，有上限）、滚轮/双指缩放、拖拽平移；
  空格开始/暂停，`.` 单步，R 重置；所有操作有键盘等价方式。
- **分享码**：场景序列化为紧凑 JSON 再 base64，粘贴即可复现（只含天体初始状态与参数，校验长度与字段，非法输入友好报错）。
- **可访问性**：拖尾与碰撞闪光在 prefers-reduced-motion 下降级；能量曲线有数值读数，不只靠图形。
- **测试接缝**：沿用观测台只读 `observatoryInfo()`，扩展：当前场景、t、总能量、挑战进度；
  语义动作 `sandboxStep(n)`：推进 n 个固定步长（E2E 不依赖真实时间流逝）。

## 测试决策

- **好测试的标准**：断言物理可观测量与挑战结果（能量漂移、是否逃逸、累计转角、完成判定），不断言渲染像素。
- **数据层（smoke）**：
  - softening 力律在 r=0 有限，且与 nm20 数值一致（ε=0.5 时 1/(0+0.25)=4.0，r=1 时 0.8）；
  - 成对计数：N 个天体每步计算 N(N−1)/2 对（与 nm19 一致）；
  - 两体圆轨道：推荐步长下 10 圈后相对能量漂移 < 1%、轨道半径漂移 < 1%；步长放大 10 倍时漂移显著增大（证明「破坏实验」现象存在）；
  - ε=0 的近距离擦肩场景：能量出现断崖（大于阈值），ε 合理时不出现；
  - 三个挑战的参考解（关卡数据自带）必须判定通过、明显错误的输入判定失败；
  - 确定性：同输入同步数结果逐位相同。
- **E2E**：传送到沙盒 → 用真实指针拖拽放置一颗卫星 → 语义动作推进若干步 → 断言轨迹与能量读数出现；挑战「三圈不坠毁」用关卡参考解的初速度（真实拖拽或输入框）→ 推进 → 断言通过与个人最佳记录；
  破坏实验：把 ε 滑块调到 0 → 推进 → 断言界面出现「能量断崖」提示。
- **先例**：observatory-minigames 的 NFW 拟合样板（纯函数 + 种子 + 宿主 E2E）；runner 的「浏览器无报错」断言。

- 不新增四选一题目（ADR-0001）；讲解只复用 nm19、nm20、nm6、dm4 的知识点，代码注释标注题 id。
