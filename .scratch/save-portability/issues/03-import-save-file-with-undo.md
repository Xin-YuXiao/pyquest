# 03: 导入存档文件（预览 + 覆盖确认 + 撤销上次导入）

Status: ready-for-agent
Type: task
Blocked by: 01, 02

## 要做什么

标题画面新增「导入存档」（无存档时也显示）：选择文件 → 01 校验 → 有错误则显示错误且不做任何改动；
否则显示预览（导出时间、当前章节、各章进度摘要、作答记录条数、warnings 列表）→ 若当前已有存档，
提示将被覆盖 → 确认后先把当前存档写入备份键，再一次性写入导入的存档，按存档落点进入游戏。
备份存在时标题画面显示「撤销上次导入」，执行后恢复备份并删除备份键。

## 验收标准

- [ ] E2E 往返：第一章碎片 2/3 → 导出 → 清空存储刷新 → 导入该文件 → 预览显示第一章 → 确认 → 进度 2/3，
      `state()` 与导出前一致
- [ ] E2E 撤销：已有第二章存档时导入第一章存档 → 确认 → 撤销上次导入 → 回到第二章存档，撤销按钮消失
- [ ] E2E 坏输入：导入非 JSON 文件、`v: 99` 文件、学习报告 JSON，分别显示对应错误，原存档逐字节不变
- [ ] 有 warnings 时必须再点一次确认才导入
- [ ] 导入过程中任何异常都不留下半写入的存档（单元测试模拟写入失败）
- [ ] `npm run check` 全绿
