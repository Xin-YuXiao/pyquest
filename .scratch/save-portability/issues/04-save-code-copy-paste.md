# 04: 存档码（复制 / 粘贴迁移进度）

Status: needs-info
Type: task
Blocked by: 03

## 要做什么

「复制存档码」把存档（去掉原始作答日志，保留进度、每题汇总与复习状态）压缩编码成一段带前缀的文本复制到剪贴板，
并提示「存档码不含完整作答日志，需要完整数据请导出文件」；标题画面「导入存档」里提供「粘贴存档码」，
走与文件导入完全相同的校验、预览、确认、备份流程。浏览器不支持压缩流时退化为不压缩编码。

开工前确认 spec 待决策 1（是否做存档码），并核实课程机房浏览器对压缩流与剪贴板接口的支持。

## 验收标准

- [ ] 单元测试：编码/解码往返一致（压缩与退化两条路径）；前缀错误、截断、乱码均返回明确错误
- [ ] 典型通关全部 11 章的存档码长度记录在 Comments（作为是否可用的依据）
- [ ] E2E：复制存档码（读取剪贴板或页面上的文本框）→ 清空存储 → 粘贴导入 → 进度一致
- [ ] 剪贴板接口不可用时提供可手动全选复制的文本框
- [ ] `npm run check` 全绿
