# 03: 数据层开启类型检查（章节注册表、地图构建器、题库）

Status: ready-for-agent
Type: task
Blocked by: 02

## 要做什么

数据层被纳入类型检查。章节配置、地图定义、道具描述、题目和题池都有准确的类型。以后写错章节字段、题目字段，CI 会直接报出来。

- 补全共享类型模块中的题目（四选一与填空以 fill 区分的可区分联合，为新题型预留判别字段）、题池、章节配置（主题、题池映射、NPC 台词表「静态数组或函数」两种形态、胜利文案、可选的跨章问候与自管台词函数）、地图定义、道具描述。
- 把现有 PropDef / Interactable typedef 从场景基类迁到共享类型模块，并修正解锁条件的类型：{ 章, 标志 } 对象或以全局状态为参数的函数，而不是现在注释里写的字符串数组。
- 数据层三个模块加入检查范围，修掉报错。

## 验收标准

- [ ] 数据层三个模块在检查范围内，零报错
- [ ] PropDef 的解锁条件类型与地图构建器的实际用法一致；场景基类改为引用共享类型模块
- [ ] 本批改动只有 JSDoc 注释和等价改写；若发现真 bug，单独提交并在提交说明中标注
- [ ] 人为在某章配置里把字段写错类型（如 shardsNeeded 写成字符串），typecheck 失败（验证后撤回，记在 Comments）
- [ ] npm run check 全绿（E2E 证明运行时零变化）
