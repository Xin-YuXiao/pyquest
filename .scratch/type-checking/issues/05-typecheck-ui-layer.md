## 验收标准

- [ ] ui 层全部模块在检查范围内，零报错

- [ ] 碎片入袋事件的 detail（gained、duration）有类型，发出方与接收方一致
- [ ] 本批没有用户可见的行为变化（11 章 E2E 通过）
