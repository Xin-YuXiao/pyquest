# 05: 减少动态效果：单一判定 + 补齐所有降级点

Status: ready-for-agent
Type: task
Blocked by: 03

## 要做什么

- 设置面板新增「减少动态效果：跟随系统 / 开 / 关」，默认跟随系统；
- 一个全局判定函数 + body 上的类；CSS 中现有的 prefers-reduced-motion 规则同时匹配该类；
- 补齐目前未降级的动效：圆形转场（改为瞬切或短淡入淡出）、受击镜头震动与缩放、开门镜头震动、答错面板抖动、答题面板弹出、HUD 碎片 / 扣心跳变动画、符文石呼吸与心形掉落浮动；
- 「碎片入袋」飞行的现有降级改为读同一个判定。

## 验收标准

- [ ] E2E：设置为「开」时答错一题，面板不出现抖动动画（检查元素无运行中的 animation）；受击时相机不震动（只读查询镜头震动状态或断言 shake 未被调用的外部效果）
- [ ] E2E：Playwright `reducedMotion: 'reduce'` 上下文 + 设置「跟随系统」，跑通第一章主线（流程不变）
- [ ] E2E：设置为「关」时即使系统偏好 reduce，动效仍正常播放
- [ ] 现有 11 章 E2E 原样通过；`npm run check` 全绿
