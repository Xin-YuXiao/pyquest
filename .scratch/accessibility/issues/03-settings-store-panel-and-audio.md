# 03: 设置存储 + 设置面板 + 可见的静音开关与音量

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

- 新增设备级设置存储（独立于存档的键，推荐 `pyquest:settings:v1`，形状见 spec 实现决策）；读写失败时用默认值，不影响游戏；存档的清档只清存档键；
- 设置面板：标题页「设置」按钮 + 游戏内入口（按 spec 待决策 2 的推荐：自由探索时 Esc + HUD 齿轮按钮）；面板是模态对话框，焦点规则同 01，打开时暂停场景；
- 第一批设置项：音效开关、音量滑块；音效模块加主增益节点；M 键与界面开关写同一份静音状态并持久化；
- 为后续工单预留字号、减少动态效果、触控层三个设置项的位置（本工单不实现其效果）。

## 验收标准

- [ ] E2E：在标题页打开设置、切换为静音 → 进入游戏后按 M 再切换一次 → 刷新页面后静音状态与最后一次一致
- [ ] E2E：调节音量后刷新，滑块值保留
- [ ] E2E：点「新的冒险」（确认清档）后设置仍保留，存档已清
- [ ] localStorage 不可用（Playwright 中模拟抛错）时游戏仍可正常开始
- [ ] `npm run check` 全绿
