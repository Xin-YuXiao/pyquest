# 02: HUD、对话框、世界地图、标题页、胜利页的读屏语义与焦点

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

把 01 的焦点与语义做法推广到其余 DOM 浮层：

- HUD：爱心与碎片计数提供文字替代（「生命 5 / 6」「证据碎片 2 / 3」，碎片名取本章 shardLabel）；目标提示为 polite live region，只在目标变化时播报；
- 对话框：非模态 dialog 角色，台词以整句写入 live region，打字机效果只作用于视觉层；
- 世界地图：模态对话框语义，打开时焦点落到当前所在章地标，Tab 在已解锁地标间移动、Enter 传送、Esc 关闭；
- 标题页、胜利页：打开即聚焦主按钮；胜利页标题与统计可读；
- 星空、金印、像素图标等装饰元素对读屏隐藏（核实现有 aria-hidden 覆盖完整）。

## 验收标准

- [ ] E2E：HUD 的可访问文本随答对碎片符文更新为「… 1 / N」
- [ ] E2E：与引导石碑对话，live region 中出现完整的第一句台词（不是半句）
- [ ] E2E：Tab 打开世界地图后焦点在当前章地标；Esc 关闭后焦点归还画布
- [ ] E2E：胜利页出现时焦点在「进入下一章」按钮上
