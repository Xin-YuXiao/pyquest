# 05: 摸底结果进作答记录与学习报告

Status: needs-info
Type: task
Blocked by: 03, ../learning-records/issues/01

## 要做什么

- 摸底的每一题写入作答记录（来源标记为 placement，与正常符文作答区分），以及一条摸底结果记录
  （日期、各章是否通过、建议起始章、学生是否接受建议）。
- 学习报告（learning-report）若已落地：增加「摸底结果」小节（放行了哪些章、摸底答对率、是否接受建议）；
  若未落地，只保证记录字段可被其读取，并在 Comments 写明对接约定。
- 统计口径：摸底作答**不**计入各章的「首答正确率」，单独统计。

## 验收标准

- [ ] E2E：完成摸底后接缝读到的作答记录包含 placement 来源条目与一条结果记录
- [ ] 旧存档无摸底记录时报告与读档正常
- [ ] `npm run check` 全绿
