# 01: 摸底规则拍板（通过规则 / 范围 / 入口 / 文案）

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

和助教 / 课程负责人过一遍 spec「待决策」1-5，书面定稿；并确认两类界面文案草稿（可由 agent 起草）：

1. 结果页文案（全部通过 / 部分通过 / 未通过三种情形，语气鼓励、不贬低）；
2. 第一至三章石碑 / 长老的 `placed` 台词（被放行后第一次回来时说的话）。

## 验收标准

- [ ] 待决策 1-5 都有书面结论（采用推荐 / 改为某方案 + 理由）
- [ ] 结果页三种情形文案、W1-W3 的 `placed` 台词经助教确认，记录在 Comments
- [ ] spec 的「待决策」更新为「已决策」
