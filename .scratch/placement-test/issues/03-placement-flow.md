# 03: 摸底测试流程（标题入口 → 逐章抽题 → 结果页 → 落点）

Status: needs-info
Type: task
Blocked by: 01, 02

## 要做什么

- 标题画面新增「我学过 Python（摸底测试）」入口（按 01 号确定的时机显示）。
- 摸底覆盖层：顶部进度（第几题 / 共几题、正在测第几章）；答题复用答题面板的「练习模式」
  （不扣心、不发奖励、不改符文槽状态——若 mistake-review 的复习模式 prefactor 尚未落地，本工单实现最小练习模式并与之约定共用）。
- 抽题：按 01 号规则从 W1-W3 现有题池抽取；摸底用题不写入「已答题」集合。
- 判定：按 01 号通过规则逐章推进，未通过即停止。
- 结果页：每章掌握情况 + 建议起始章；「从第 N 章开始」→ 放行前缀章节（02 号的 `placed`）并落到第 N 章野外；
  「还是从第一章开始」→ 正常新游戏。
- 接缝 `placement()` 返回摸底进行状态与结果。

## 验收标准

- [ ] E2E `e2e-placement`：答对前两章、答错第三章 BOSS 档题 → 结果页建议第三章 → 接受 → 落点与放行状态正确
- [ ] E2E：拒绝建议 → 第一章开始、无任何章节被放行
- [ ] 摸底全程心数不变、碎片不变、符文槽状态不变
- [ ] 摸底题来自 W1-W3 现有题池（smoke 或 E2E 断言题 id 归属）
- [ ] `npm run check` 全绿
