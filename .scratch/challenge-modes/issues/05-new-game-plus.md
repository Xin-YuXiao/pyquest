# 05: 二周目（New Game+）

Status: needs-info
Type: task
Blocked by: 01, 03

## 要做什么

- 全部通关后，胜利封印页与标题画面出现「开启二周目」（二次确认）；开启后主线进度清零、周目数 +1，元进度（知识卡、成就、挑战纪录、打卡）全部保留。
- 二周目规则（以 03 结论为准）：小怪加强；抽题优先排除历史上答对过的题（以元进度的知识卡集合为准），池中不够再回退到现有抽题规则；BOSS 符文答错即换题。
- 标题画面「继续冒险」显示周目，如「二周目 · 第 3 章」；HUD 显示周目标记。
- 周目字段为主线存档的可选字段，老存档缺省为一周目。

## 验收标准

- [ ] E2E：用测试接缝把全部章节标记通关并解锁若干知识卡 → 开启二周目 → 进入第一章打开一块碎片符文，抽到的题不在已收集知识卡集合中（池内有未答过的题时）
- [ ] 二周目开启后知识卡与成就数量不变；主线章节进度全部归零
- [ ] smoke 或单元测试：「优先未答对过的题」抽题规则在池耗尽时回退正确
- [ ] npm run check 全绿
