# 01: 答题会话 + 每日星图样板

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

打通「入口 → 确定性抽题 → 连续答题 → 结果页 → 打卡存盘」的整条链路：

- prefactor：答题面板不再直接暂停/恢复所属场景，改为接收「打开时 / 关闭时」钩子；主线符文的行为不变（主线调用方传入暂停/恢复当前场景）。
- 新增确定性抽题纯函数：种子 + 候选题池 + 题数 + 分层权重 → 不重复的题目列表；复用地图生成已有的种子化随机数函数。
- 新增答题会话界面：顺序出题（复用答题面板的渲染、选项、填空、键盘 1-4/Enter），会话中答错不扣主线爱心、答对不发碎片；结束后结果页列出每题对错并可展开解析。中途退出有确认，退出不计成绩。
- 每日星图：通关第一章后解锁；种子 = 本地日期的稳定哈希；题源 = 已通关章节的全部题池，分层抽 5 题；当天首次完整提交才记成绩与连续打卡天数，之后显示「今日已完成」并可重看结果。
- 长期数据写入元进度存档（与 achievements-codex 共用的模块；若该模块尚未落地，按 achievements-codex 规格的形状由本工单先实现）。答对的题同步解锁知识卡（若图鉴已落地）。
- 入口：标题画面「挑战」按钮（未解锁时显示解锁条件）。
- 测试接缝：只读快照含会话状态；语义动作「以指定日期开启每日星图」。

## 验收标准

- [ ] smoke：固定日期 + 固定已通关章节集合 → 抽题结果稳定（锁定期望题号）、无重复、全部来自已通关章节题池
- [ ] E2E（新增非章节套件，挂进 npm run test:e2e 的额外套件列表）：通关第一章 → 注入日期开启每日星图 → 真实 DOM 答完 5 题 → 结果页出现、连续打卡 = 1 → 刷新后显示「今日已完成」
- [ ] 会话中答错不改变主线爱心；主线全部章节 E2E 不受答题面板 prefactor 影响
- [ ] 中途退出确认后，不记成绩、不计打卡
- [ ] npm run check 全绿
