Status: needs-info

## 要做什么

- 「新的冒险」时可勾选硬核模式（周目修饰写入主线存档，可选字段，老存档缺省为否）。
- 硬核下：答错扣心没有「最低留 1 颗心」保护，扣到 0 走既有死亡 → 回本章野外重生流程；答错的符文石清除其抽题记录并立即存档（刷新页面也无法回到同一道题）；其余规则以 03 结论为准。
- HUD 显示硬核标记；标题画面「继续冒险」按钮显示「硬核」字样。
- 测试接缝快照包含周目修饰；章节 E2E runner 增加可选的「硬核」参数。

## 验收标准

- [ ] E2E：硬核新游戏 → 把爱心压到 1（测试接缝）→ 故意答错 → 角色死亡并回本章野外；再次打开同一符文石，题目与之前不同（池内有其他可抽题时）
- [ ] 非硬核存档行为完全不变（全部章节 E2E 通过）
- [ ] 老存档读档后为非硬核
- [ ] npm run check 全绿
