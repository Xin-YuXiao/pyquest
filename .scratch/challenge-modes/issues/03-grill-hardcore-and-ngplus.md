# 03: 硬核模式与二周目规则（grilling）

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

这是玩法改动，需要维护者拍板，结论写回 Comments 并更新 spec：

- 硬核：答错是否完全取消「最低留 1 颗心」保护？死亡后回本章野外是否足够（还是回到章首、清本章碎片）？答错换题是否也适用于祝福符文与 BOSS 符文？
- 二周目：小怪加强数值（推荐生命 +1、移速 +15%）、BOSS 是否加强（推荐不加血，只加「答错换题」）、抽题「优先未答对过的题」的回退顺序、开启二周目是否覆盖当前主线存档（推荐覆盖并二次确认）。
- 硬核能否与二周目叠加（推荐可以）；硬核是否只能在新冒险开始时选择（推荐是，中途不能切换）。
- 与 difficulty-economy（爱心上限成长、金币商店）的关系：若它先落地，硬核下是否禁用回复药水等。
- 挑战作答是否进入学习统计（推荐全部记录、带模式标签、报告默认只看主线）。
