# 02: 限时试炼（含「不限时练习」变体）

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

- 挑战入口新增限时试炼：通关任意一章后解锁；可多选已通关章节作为题源（题源 = 这些章的全部题池，随机顺序）。
- 规则：初始 90 秒；首答正确 +8 秒，答错 −10 秒并直接进入下一题；计时归零或题源耗尽结束。
- 结果页：答对题数、最长连对、用时；每个「章节组合」保存一条本地最佳纪录（元进度），破纪录时有提示。
- 「不限时练习」变体：同样题源与流程，不计时、不计纪录（给需要更多阅读时间或使用读屏的学生）。
- 倒计时显示对读屏友好（不每秒播报，只在剩余 30 / 10 秒时播报一次）。
- 测试接缝：语义动作「计时快进 N 秒」。

## 验收标准

- [ ] 单元测试或 smoke 覆盖计时规则：加时、扣时、归零结束、题源耗尽提前结束
- [ ] E2E：开启第一章限时试炼 → 答对 1 题（剩余时间增加）→ 快进至归零 → 结果页显示答对 1 题，最佳纪录写入；再玩一局更差的成绩，最佳纪录不变
- [ ] 「不限时练习」不出现倒计时、结束不写纪录
- [ ] npm run check 全绿
