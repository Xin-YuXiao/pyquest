# 03: E2E 与构建产物断言「页面零外链请求」

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

维护者以后不管引入什么第三方资源（字体、统计脚本、CDN 库），只要页面在运行中向非本地域名发请求，CI 就失败，并在输出里列出具体 URL。

做法：

- E2E 声明式 runner 继续拦截外链（保证测试确定性），但把每个外链请求的 URL 记下来。在公共收尾断言（与「浏览器无报错」并列）里新增「页面零外链请求」，11 章脚本自动获得，无需逐章修改。
- 新增构建产物检查：扫描 dist 里的 html 与 css，断言不含第三方域名的 URL，并接入 CI 的构建步骤之后。

## 验收标准

- [ ] 11 章 E2E 都输出并通过「页面零外链请求」断言
- [ ] 人为在页面头部加回一条 Google Fonts 链接，E2E 失败，失败信息里包含该 URL；构建产物检查同样失败（验证后撤回，在 Comments 记录验证过程）
- [ ] 构建产物检查对本地相对路径和 data: URL 不误报
- [ ] CI 工作流在构建之后运行构建产物检查
- [ ] README「测试」一节说明这条断言的含义和排查方法
- [ ] npm run check 全绿
