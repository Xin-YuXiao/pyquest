# 04: 字体下载体积测量与 CI 预算

Status: ready-for-agent
Type: task
Blocked by: 01, 03

## 要做什么

维护者能看到「首屏要下载多少字体字节」，CI 在这个数字超出预算时失败。以后加题、加章、换字体导致字体切片变多，都能被发现。

做法：

- 在 E2E 中统计两个时间点前所有字体请求的字节数（未压缩传输量）：①标题画面出现；②第一道题的答题面板打开。
- 把首次测量结果作为基线，写进一个预算配置（基线加 20% 余量，余量比例可在 Comments 讨论），超出即失败。
- 测量结果在 E2E 输出里打印，方便趋势对比。

## 验收标准

- [ ] 第一章 E2E 输出「标题画面字体字节数」和「首题字体字节数」两个数值
- [ ] 预算配置文件存在，数值为实测基线加余量，并注释测量日期和环境
- [ ] 人为把预算调低到基线以下，E2E 失败，信息说明超出多少（验证后恢复）
- [ ] 基线数值与各字体族的占比记录在本工单 Comments，作为 05 的输入
- [ ] npm run check 全绿
