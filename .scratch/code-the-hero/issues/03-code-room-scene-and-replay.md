# 03: 代码训练场场景与动作回放（用预置动作演示）

Status: ready-for-agent
Type: task
Blocked by: 02

## 要做什么

新增「代码训练场」场景：左侧网格小房间（复用现有地面/道具贴图与勇者动画；占位素材环境下同样可用），右侧编辑器区域（本工单先只读显示起始代码与参考解）与输出区。
给定一份动作列表即可回放：勇者逐步行动、播放/暂停/单步/倍速、回放中高亮动作对应的代码行、结束时显示判定与原因。
本工单用关卡数据里的「参考动作列表」驱动回放（不运行 Python），入口暂只通过测试接缝的语义动作 `openCodeRoom(levelId)` 打开，正式入口在 05 号。

## 验收标准

- [ ] `openCodeRoom` 打开样板关卡，回放参考动作后显示「过关」，勇者最终位置与 `simulate` 结果一致
- [ ] 播放/暂停/单步/倍速可用（键盘与鼠标）；回放中当前行高亮正确
- [ ] 失败回放（例如故意截断动作列表）显示具体原因
- [ ] 退出训练场回到进入前的场景与位置，主线进度不变
- [ ] 测试接缝新增只读 `codeRoom()`（关卡、动作、判定、回放进度）
- [ ] E2E：`openCodeRoom` → 回放 → 断言过关与最终位置；浏览器无报错
- [ ] `npm run check` 全绿
