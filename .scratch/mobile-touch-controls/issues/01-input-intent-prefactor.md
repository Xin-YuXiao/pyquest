# 01: 输入抽象 prefactor：键盘汇入「移动意图 + 动作」

Status: resolved
Type: task
Blocked by: None (can start immediately)

## 要做什么

先把输入改造得「容易接触屏」，玩家可感知的行为零变化：

- 玩家实体每帧读取一个 8 方向「移动意图」（x、y ∈ {-1, 0, 1}），不再直接读键盘对象；
- 交互、攻击、世界地图、静音四个动作由场景统一订阅（键盘 E、J / 空格、Tab、M 触发），不再分散在场景、世界地图、各弹层里各自监听原始按键；
- 键盘是第一个意图 / 动作生产者；速度、朝向判定的先后顺序、斜向两轴满速的现有手感保持逐帧一致；
- 弹层（答题面板、对话、世界地图）原有的键盘行为（1-4 / Enter、E / 空格 / Enter 推进对话、Tab 开关地图）不变。

## 验收标准

- [ ] 玩家实体与场景里不再有直接读取方向键 / WASD 状态的代码路径，移动只经由移动意图
- [ ] 四个动作有统一的订阅入口，键盘绑定集中在一处，可在不改玩家实体的前提下新增输入源
- [ ] 场景重启（死亡重生、传送门切场景、世界地图传送）后不残留旧监听器、不重复触发动作
- [ ] 全部 11 章 E2E 原样通过（不改任何断言）
- [ ] `npm run check` 全绿
