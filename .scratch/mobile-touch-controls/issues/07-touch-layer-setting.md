# 07: 设置项「触控操作层：自动 / 总是显示 / 总是隐藏」

Status: ready-for-agent
Type: task
Blocked by: 03, ../accessibility/issues/03

## 要做什么

自动检测可能误判（如带触屏的笔记本、外接键盘的平板），让用户自己纠正：

- 设置面板里新增三态选项，默认「自动」；
- 选择存入设备级设置存储（与无障碍设置同一处，不进存档，「新的冒险」不清除）；
- 切换即时生效，无需刷新。

## 验收标准

- [ ] E2E：桌面视口下把设置改为「总是显示」，触控层出现且摇杆可用；改回「自动」后消失
- [ ] E2E：刷新页面后设置保留；点「新的冒险」后设置仍保留
- [ ] `npm run check` 全绿
