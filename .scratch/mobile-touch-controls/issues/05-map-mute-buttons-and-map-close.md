# 05: 地图 / 静音按钮 + 世界地图可点关闭

Status: resolved
Type: task
Blocked by: 03

## 要做什么

- HUD 附近新增地图按钮、静音按钮（触控层的一部分，桌面端默认隐藏）；
- 世界地图新增可点的关闭按钮，并支持点空白处关闭——这对桌面鼠标用户同样生效；键盘 Tab 开关不变；
- 静音按钮显示当前静音状态（音效模块补一个读取静音状态的接口），点击切换并沿用现有「已静音 / 声音已开启」提示。

## 验收标准

- [ ] 触屏 E2E：点地图按钮打开世界地图，点关闭按钮关闭；再次打开后点地图外空白处也能关闭
- [ ] 触屏 E2E：在世界地图里点已解锁地标仍能快速传送（沿用 runner 的 worldMap 步骤断言）
- [ ] 桌面 E2E：鼠标点关闭按钮可关闭世界地图（第三章 runner 的 worldMap 步骤补一条断言）
- [ ] 静音按钮的显示状态与实际静音状态一致（键盘 M 切换后按钮同步）
- [ ] `npm run check` 全绿
