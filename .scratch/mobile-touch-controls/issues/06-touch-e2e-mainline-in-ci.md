# 06: 触屏 E2E 主线进 CI

Status: ready-for-agent
Type: task
Blocked by: 02, 04, 05

## 要做什么

让触控体验有一条和键盘同等级别的自动回归：

- E2E 声明式 runner 支持「输入方式」选项（键盘 / 触屏）；触屏模式下交互、攻击改为点触控层按钮，移动由摇杆完成，答题走真实 tap；
- 选第三章样板章用横屏手机视口跑完整主线（碎片 → 封印门 → 巢穴 → 祝福符文 → BOSS 符文 → BOSS 战 → 结算 → 下一章 → 读档续玩）；
- 另加一条竖屏手机视口冒烟：进野外、摇杆移动、打开 / 关闭世界地图；
- 两条都接入 `npm run test:e2e` 与 CI。

## 验收标准

- [ ] runner 的触屏模式与键盘模式共用同一组 steps 声明，章节脚本只多一个输入方式字段
- [ ] 第三章触屏主线在本地与 CI 均通过
- [ ] 竖屏冒烟在本地与 CI 均通过
- [ ] 若触摸拖动依赖 Chromium 专有能力（CDP），在 runner 注释里说明，且仅在 Chromium 下运行
- [ ] `npm run check` 全绿，CI 绿
