# 02: 答题面板触控与小屏适配

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

让任何一道题在手机横屏 / 竖屏上都能完整作答：

- 答题背景层在横屏下也可纵向滚动（目前只有竖屏可滚动），面板设最大高度，打开时滚回顶部；
- 选项按钮、「确认 / 领取奖励」「先不回答」按钮按缩放后的实际尺寸核算，触控目标不小于 44 CSS px；
- 点选项、点确认、点领取奖励全流程在触屏上可用（选项本来就是按钮，这里核实并修掉触屏上的命中 / 双击缩放 / 文本选中问题）；
- 「碎片入袋」动画在小屏上落点仍对准 HUD 碎片计数。

## 验收标准

- [ ] 在 844×390（横屏手机）与 390×844（竖屏手机）视口下，题库里面板最高的题（按题面 + 代码 + 讲解长度挑选，先例：runner 注释里的 sp15）滚动后能看到并点中确认与领取奖励按钮
- [ ] 新增 E2E：移动视口 + hasTouch 上下文中，用 tap 完成一块碎片符文（选项 → 确认 → 领取），断言碎片数 +1
- [ ] 桌面视口下面板外观与交互不变（现有 11 章 E2E 原样通过）
- [ ] `npm run check` 全绿
