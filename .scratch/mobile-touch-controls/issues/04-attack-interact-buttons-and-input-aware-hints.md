# 04: 攻击键 / 交互键 + 按输入方式切换的提示文案

Status: ready-for-agent
Type: task
Blocked by: 03

## 要做什么

触屏用户不靠键盘就能打怪、解读符文石、和石碑 / 长老对话、检查封印门：

- 右下角攻击键：点按挥剑，按住按现有攻击冷却连发；
- 交互键：文字随附近对象变为「解读 / 对话 / 检查」，对话进行时变为「继续」；无可交互对象时置灰；判定复用现有交互提示的距离判断与半径常量；
- 多点触控：按住摇杆移动的同时可点攻击键；
- 提示文案按最近使用的输入方式切换：交互提示条、对话框「继续」提示、标题页操作说明从同一份「操作提示词」映射取词（键盘显示键帽，触屏显示按钮名）。

## 验收标准

- [ ] 触屏 E2E：走到一块碎片符文旁，交互键文字为「解读」，点击后答题面板打开
- [ ] 触屏 E2E：按住摇杆的同时点攻击键，挥剑生效（小怪受击或攻击冷却被触发，用只读状态断言）
- [ ] 触屏 E2E：与引导石碑对话，用交互键逐句推进到对话结束
- [ ] 键盘用户看到的提示仍是 `E` 键帽，触屏用户看到【交互】；切换输入方式后提示随之切换
