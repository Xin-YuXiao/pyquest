# 03: 触控层骨架 + 虚拟摇杆移动

Status: resolved
Type: task
Blocked by: 01

## 要做什么

触屏设备上出现左下角虚拟摇杆，拖动即可移动勇者：

- 触控层是覆盖整个视口的固定层（不在 #ui-scale 设计坐标系里），按钮用 CSS 像素定尺寸、避开 safe-area；横屏贴左下角，竖屏放在画布下方留白区；
- 自动检测：pointer: coarse 或收到首个触摸指针事件即显示；桌面端默认不显示；
- 摇杆超过死区（半径 25%）后按角度量化为 8 方向移动意图，与键盘同一种数字量（见 spec 待决策 1，按推荐实现）；
- Pointer Events + 按 pointerId 跟踪，`touch-action: none` 只加在触控层上；
- 松手、pointercancel、切后台、旋转屏幕、场景切换、玩家死亡时摇杆复位，勇者停下；
- 答题面板 / 世界地图 / 标题页 / 胜利页打开时整层隐藏，关闭后恢复。

## 验收标准

- [ ] 移动视口 + hasTouch 的 E2E：进入第一章野外，拖动摇杆向右 1 秒，玩家 x 坐标增大；松手后坐标不再变化
- [ ] E2E：打开答题面板时触控层不可见且不拦截点击，关闭后恢复可见
- [ ] 桌面视口（无触摸）下触控层不渲染，现有 11 章 E2E 原样通过
- [ ] 手动核对清单写进工单 Comments：iOS Safari / Android Chrome 各一台真机横竖屏走一遍（无真机时注明未做）
- [ ] `npm run check` 全绿
