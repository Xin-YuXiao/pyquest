# 06: 解锁轻提示 + 完成度统计（手册首页与标题画面）

Status: needs-info
Type: task
Blocked by: 04

## 要做什么

- 解锁轻提示：屏幕角落的独立提示元素（不复用底部交互提示条），显示徽章名与一句说明，数秒后自动消失；多个解锁排队依次显示。
- 答题面板、对话框、世界地图/手册打开期间解锁的徽章先入队，面板关闭后再弹。
- 尊重「减少动态效果」：静态出现、无飞入；提示元素对读屏可读（礼貌型 live region）。
- 完成度：手册首页和标题画面显示「知识卡 x/总数 · BOSS x/11 · 成就 x/可见总数」。
- 知识卡分页里新开放的卡在第一次被看到前带一个「新」角标；翻阅行为写入元进度（供「讲义精读」）。

## 验收标准

- [ ] E2E：答题面板打开时触发的解锁，在面板关闭后才出现提示元素
- [ ] 开启 prefers-reduced-motion 模拟时提示元素无动画（检查计算样式或动画列表为空）
- [ ] 标题画面在有元进度时显示完成度，没有元进度时不显示该行
- [ ] npm run check 全绿
