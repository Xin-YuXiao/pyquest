# 01: 元进度存档 + 知识卡图鉴样板（手册「知识卡」分页）

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

打通「答对 → 收集 → 翻阅 → 清档后仍保留」整条链路的样板：

- 新增元进度存档模块（独立存储键，与主线存档分离）。主线「新的冒险」与胜利页「重新开始」只清主线存档，元进度保留。
  这个模块与 challenge-modes 共用；本工单先落地，challenge-modes 直接复用。
- 首次加载时回填：主线存档里已答对的题目 → 知识卡。
- 任何一次答对主线题库里的题，都解锁对应知识卡（写入元进度并立即存盘）。
- 世界地图面板顶部加分页条：「地图 / 知识卡」（BOSS 与成就分页由后续工单加）。默认停在地图页，现有 Tab 行为与世界地图 E2E 不变。
- 知识卡分页：按「章 → 题池」分组；已收集的卡显示题面、代码块（沿用语法高亮）与解析，不显示选项与答案序号；未收集的卡显示剪影与「本题池还差 N 张」；顶部显示「知识卡 x / 总数」（总数由题库动态计算）。
- 标题画面新增「冒险手册」按钮：无主线存档时也能打开，只读元进度。
- 测试接缝只读快照新增 meta 字段；新增「清空元进度」语义动作（测试隔离用）。

## 验收标准

- [ ] 新游戏答对第一章任意一块碎片符文后，打开手册的知识卡分页能看到这张卡，且卡上有该题的解析文本、没有选项
- [ ] 刷新页面后知识卡仍在；点「新的冒险」并确认后，知识卡仍在，而主线进度已清零
- [ ] 用 v2 老存档（已答对若干题）首次进入新版本，这些题自动出现在图鉴里；用测试接缝 gotoChapter 跳过的章节不会凭空出现知识卡
- [ ] 知识卡总数等于题库题目总数；每个题池都能反查到所属章（smoke 校验）
- [ ] 世界地图现有 E2E（第三章的 worldMap 步骤：节点数、锁定、已通关、当前章高亮、点击传送）不受影响
- [ ] 新增一个非章节的 E2E 套件覆盖上面第 1、2 条，并挂进 npm run test:e2e（run-e2e 目前只按章节号枚举脚本，需加「额外套件」列表；若已有则复用）
- [ ] npm run check 全绿
