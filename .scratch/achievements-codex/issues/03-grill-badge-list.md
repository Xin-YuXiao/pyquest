# 03: 成就清单定稿（grilling）

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

和维护者/课程方过一遍规格里「首批成就提案」表，定下：

- 每个成就的最终名称、说明文案、分类、是否隐藏、隐藏提示语
- 阈值：「又快又准」的分钟数、「讲义精读」的张数、「百卡学者」的张数（建议找一位没玩过的同学试玩一章后校准）
- 反乱猜原则是否全部接受：学习向成就一律基于首答；不设累计答题/累计尝试类成就；速通类要求零答错
- 依赖其他 effort（错题本、彩蛋、挑战模式）的成就，在对应功能上线前隐藏不显示——确认这个处理

结论写回本文件的 Comments，并同步更新 spec 的成就表。

## 验收标准

- [ ] 成就表定稿（名称/说明/分类/隐藏/阈值/依赖）写入 spec
- [ ] 反乱猜原则的取舍有明确结论
- [ ] 04、05 的 Status 可改为 ready-for-agent
