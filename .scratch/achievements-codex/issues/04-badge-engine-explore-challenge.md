# 04: 成就引擎 + 章内战绩 + 探索向/挑战向首批徽章

Status: needs-info
Type: task
Blocked by: 01, 03

## 要做什么

- 成就定义改为纯数据清单（id、名称、分类、说明、隐藏、隐藏提示、订阅事件、判定条件、依赖功能开关）。
- 成就引擎：订阅 HUD 刷新事件与新增的少量语义事件（答题结果、章节通关、场景进入、对话结束），只评估订阅了该事件且未解锁的成就；解锁写入元进度。
- 新增「章内战绩」：每章的活跃游玩时长（仅本章场景激活且页面可见时累计；注意胜利页的「冒险用时」是墙钟时间，不能复用）、被小怪打中次数、答错次数、死亡次数。作为主线存档每章进度下的可选字段（缺省为空，老存档兼容）。
- 本工单实现不依赖学习记录的那批徽章：初识咒语、地图测绘员、全境踏足、石碑的倾听者、回乡之旅、无伤封印、又快又准、毕业典礼、一池通晓、百卡学者、图鉴大全、讲义精读（以 03 定稿为准）。
- 手册新增「成就」分页：按三类分组，已解锁显示名称/说明/解锁时间，未解锁显示名称与说明（隐藏成就显示问号与提示语），依赖功能未上线的成就不显示。

## 验收标准

- [ ] 成就清单的数据完整性由 smoke 校验（id 唯一、分类合法、隐藏成就必有提示语、依赖开关名合法）
- [ ] E2E：godmode 下清掉第一章（无伤、无答错）后，「无伤封印」解锁并出现在成就分页；故意答错一次后重开新游戏再通关，「无伤封印」不会因这次解锁（可用「清空元进度」隔离）
- [ ] 章内活跃时长在页面切到后台时停止累计（单元测试或 E2E 用 visibilitychange 模拟）
- [ ] 老存档（没有章内战绩字段）读档正常，章节 E2E 全部不受影响
- [ ] npm run check 全绿
