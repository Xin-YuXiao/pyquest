# 02: BOSS 图鉴分页

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

手册新增「BOSS」分页：

- 每章一张 BOSS 卡，未击败时为剪影（只显示「第 N 章 · ？？？」），击败后显示 BOSS 名、章标题与副标题、野外名与巢穴名、本章知识点概述（只用章节注册表现有字段拼接，不新写内容）、首次击败日期。
- 击败记录写入元进度（「已见 BOSS」列表），所以「新的冒险」之后仍保留；首次加载时从主线进度回填。
- 分页标题显示「BOSS x / 11」（总数取章节注册表长度）。

## 验收标准

- [ ] 第一章用测试接缝 slayBoss 击败 BOSS 后，BOSS 分页里第一章的卡从剪影变为完整卡，显示 BOSS 名与章标题
- [ ] 「新的冒险」后该卡仍为已解锁状态
- [ ] 老存档里已通关的章节，首次进入新版本时 BOSS 卡自动解锁
- [ ] E2E 套件（01 新增的那个）补上 BOSS 分页断言
- [ ] npm run check 全绿
