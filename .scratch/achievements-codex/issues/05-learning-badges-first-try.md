# 05: 学习向徽章（基于首答）+ 知识卡「首答正确 / 曾答错」标记

Status: needs-info
Type: task
Blocked by: 03, 04, ../learning-records/issues/01

## 要做什么

接入学习记录（每次作答的对错与第几次尝试）后：

- 实现依赖首答判定的徽章：零失误封印、两部贯通、驯龙者（以 03 定稿为准）。「首答」= 该题在主线里第一次被作答时的对错；同一块符文石因答错重新作答不算首答。
- 知识卡上显示小标记：首答正确 / 曾答错后学会（数据只读学习记录，不另存）。
- 学习记录落地前已经解锁的知识卡没有首答数据 → 不显示标记（不猜测）。

## 验收标准

- [ ] E2E：第一章所有符文都一次答对 → 「零失误封印」解锁；任一符文答错过一次 → 本章不解锁
- [ ] 知识卡上「曾答错」标记与学习记录一致；没有记录的旧卡不显示标记
- [ ] 不存在任何按「累计作答次数 / 累计答对次数」解锁的成就（smoke 对成就清单做一条约束检查）
- [ ] npm run check 全绿
