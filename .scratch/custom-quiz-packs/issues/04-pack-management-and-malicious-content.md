# 04: 题包管理（列表/删除/版本覆盖/上限）+ 恶意内容 E2E

Status: ready-for-agent
Type: task
Blocked by: 02

## 要做什么

- 练习场列表：每个题包显示标题、作者、版本、题数、已答对题数/总数、最佳成绩、最后练习时间。
- 删除题包（二次确认），同时删除其进度。
- 同 id 同版本重复导入 → 提示「已存在」；同 id 新版本 → 询问覆盖，进度按题 id 保留，已被删掉的题的进度丢弃；同 id 旧版本 → 提示「比已导入的旧」并默认不覆盖。
- 体积/题数上限与本地存储配额不足的处理：给出明确提示，不留下半写入状态。
- 拖放导入（在粘贴、文件选择之外）。
- 恶意内容 E2E：题面/选项/解析/代码/提示语里放 `<script>`、`<img src=x onerror=...>` 等，导入后打开该题，断言没有脚本执行（全局标志变量未被设置）、文本按字面显示。

## 验收标准

- [ ] E2E：导入 v1 → 练习答对 2 题 → 导入同 id 的 v2（删掉其中一题、新增一题）并确认覆盖 → 进度只保留仍存在的那道题
- [ ] E2E：恶意内容题包导入并练习后，全局标志变量仍未定义，页面无报错
- [ ] 超过体积上限的题包被拒并给出提示
- [ ] npm run check 全绿
