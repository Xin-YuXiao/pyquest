# 01: 加固代码高亮（渲染安全边界的 prefactor）

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

题包会让任意外部代码走答题面板的代码高亮，先把这条路径修成「结构良好、只输出转义文本 + 固定的高亮标签」：

- 修复已核实的缺陷：字符串字面量被包进 `class="str"` 的标签后，函数名规则（含 `str`）会再次匹配属性里的 `str`，产出嵌套损坏的标签（`print("hi")` 即可复现）。主线所有含字符串字面量的题目都受影响。
- 建议改为「先把源码切分成词元（字符串、注释、关键字、函数名、数字、`___` 占位、普通文本），再对每个词元转义后统一输出」，不再在已生成的 HTML 上多轮正则替换。
- 行为保持：关键字/函数名/字符串/数字的高亮类名不变；填空占位符仍渲染为带固定 id 的空槽（答题面板选中选项时依赖它）。
- 顺带确认：选项、解析的转义函数覆盖 `&` `<` `>`；题面与章标签走纯文本（已核实），保持不变。

## 验收标准

- [ ] 结构良好性测试（smoke 或单元测试层）：对含字符串字面量、数字、关键字、函数名、`___` 占位符、`<script>`、`<img onerror>` 的代码，输出解析后标签正确嵌套、无属性内嵌标签、去掉标签后的文本与原代码逐字一致
- [ ] 主线 251 题的高亮输出全部通过同一结构良好性检查（smoke 遍历题库）
- [ ] 全部章节 E2E 通过（含填空题的选中填入行为）
- [ ] npm run check 全绿
