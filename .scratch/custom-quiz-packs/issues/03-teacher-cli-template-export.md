# 03: 教师工具：校验命令 + 导出命令 + 题包模板与说明

Status: ready-for-agent
Type: task
Blocked by: 02

## 要做什么

- 校验命令（npm script）：校验一个或多个题包文件，用与游戏内完全相同的 schema 模块；输出逐条中文报错与汇总；任一失败退出码非 0。
- 导出命令（npm script）：把指定主线题池原样导出为题包——题面、代码、选项、答案、解析逐字不改（ADR-0001），label 取题目章标签，hint 取该章在答题面板里的提示语。
- 在 docs 下新增题包模板（含一道选择题、一道填空题的完整示例）和一页面向老师的使用说明：怎么写、怎么校验、怎么发给学生、学生怎么导入。
- 用导出命令生成一份示例题包（例如第一章碎片题池）放进仓库，作为说明里的样例。

## 验收标准

- [ ] smoke：导出第一章碎片题池 → 用校验命令校验导出结果必须通过；导出题目与题库逐字一致
- [ ] 校验命令对模板文件通过，对故意写错的样例给出可读报错且退出码非 0
- [ ] 文档里的步骤由一个没参与开发的人照做一遍可以完成（在 Comments 记录试读结果）
- [ ] npm run check 全绿
