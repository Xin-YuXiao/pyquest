# 06: 题包作答接入学习记录与错题本

Status: needs-info
Type: task
Blocked by: 02, 05, ../learning-records/issues/01

## 要做什么

按 05 的结论：

- 题包练习中的每次作答写入学习记录，模式标签为 `pack:<题包 id>`，题目标识用「题包 id + 题 id」避免与主线题号冲突。
- 若错题本已落地：答错的题包题目进入错题本的「题包」分组，可从错题本重做（重做仍在答题会话里进行）。
- 删除题包时，学习记录保留（历史事实），错题本里对应条目标记为「题包已删除」且不可重做。

## 验收标准

- [ ] E2E：练习题包时答错一题 → 学习记录快照里出现带 pack 模式标签的记录 →（若错题本已落地）错题本「题包」分组出现该题
- [ ] 删除题包后，学习记录条目仍在，错题本条目显示「题包已删除」
- [ ] 主线学习统计默认不包含题包作答
- [ ] npm run check 全绿
