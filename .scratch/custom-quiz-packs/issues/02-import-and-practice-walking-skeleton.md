# 02: 题包导入并练完一轮（样板）

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

打通「老师的文件 → 学生导入 → 练习 → 结果 → 进度保留」整条链路：

- 题包 schema v1 校验模块：字段与约束见 spec（选项 3–4 个、answer 合法、选项互异、fill 必有占位符、长度/题数/体积上限）。题目字段规则与 quiz-bank-lint 共用同一个 schema 模块——若它尚未落地，本工单建立该模块，主线校验以后复用。
- 标题画面新增「题包练习场」：粘贴 JSON 文本或选择文件 → 校验（失败显示逐条中文报错，定位到第几题哪个字段）→ 预览（标题、作者、题数）→ 确认导入。
- 练习：在答题会话里顺序练习（与 challenge-modes 共用；若答题会话与答题面板 prefactor 尚未落地，本工单先按 challenge-modes 01 的描述实现，以先落地者为准）。答错不给第二次机会，显示题目自带提示语与解析；不扣主线爱心、不发碎片、不进知识卡图鉴。
- 结果页 + 题包进度（答对过的题、最佳成绩）存入独立存储键，与主线存档、元进度分离。
- 测试接缝：快照含 packs；语义动作「清空题包存储」。

## 验收标准

- [ ] E2E（新增非章节套件，挂进 npm run test:e2e 的额外套件列表）：标题画面 → 题包练习场 → 文件选择注入合法题包 → 预览题数正确 → 导入 → 练完 3 题 → 结果页 → 刷新后进度保留
- [ ] E2E：注入 answer 越界的题包 → 报错文本包含题号与 answer 字段，题包未被导入
- [ ] 主线存档在整个流程前后不变（对比快照）
- [ ] schema 规则表驱动测试：合法样例通过，每条规则至少一个非法样例被拒
- [ ] npm run check 全绿
