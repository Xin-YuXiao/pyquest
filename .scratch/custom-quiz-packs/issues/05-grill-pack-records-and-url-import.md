# 05: 题包作答是否入册、是否支持 URL 导入（grilling）

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

与维护者/课程方确定：

- 题包作答是否进入学习记录（推荐：进入，带 `pack:<id>` 模式标签，学习报告默认可筛选）
- 是否进入错题本（推荐：进入，单独「题包」分组）；是否进入知识卡图鉴（推荐：不进入）
- 是否支持从 URL 导入（推荐：v1 不做，只支持文件/粘贴/拖放）
- 是否在 save-portability 的导出里附带题包（推荐：提供勾选项，缺省不附带）
- 题包是否允许声明「打乱顺序」（推荐：允许，缺省顺序）
