# 05: 核心模块测试覆盖率报告

Status: ready-for-agent
Type: task
Blocked by: 02, 04

## 要做什么

维护者能看到核心模块（全局状态、章内阶段、抽题、存档）的行覆盖率和分支覆盖率，知道还有哪些分支没测到。本阶段只报告、不设门槛（门槛是否要设，属于 spec 中的待决策项）。

## 验收标准

- [ ] 有一条 npm 脚本可生成覆盖率报告，范围限定为核心模块
- [ ] CI 在单元测试步骤输出覆盖率摘要（文字表格即可），不因覆盖率失败
- [ ] 当前覆盖率数字和未覆盖的主要分支清单记录在 Comments，供决定门槛时参考
- [ ] 覆盖率产物目录加入 .gitignore
- [ ] npm run check 全绿
