# 02: 抽题规则单元测试

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

抽题的每条规则都有独立、确定的单元测试，测试失败时直接说明哪条规则被破坏。测试使用真实题库，选题量小的真实题池（如 W1 BOSS 池）来构造边界场景，随机数用替身固定。

覆盖的规则：

1. 同一块符文石在答对之前，重复抽题返回同一道题
2. 已答对的题不会再被抽到
3. 其他符文石已抽走但还没答对的题会被避开（同池不撞题）
4. 第 3 条无法满足时（同池候选都被其他符文石占用），退而只避开已答对的题
5. 题池全部答完后允许复用（兜底），不会抛错或返回空
6. 符文石之前抽中的题已经不在本池中（例如题库调整后读旧档），就重新抽题
7. 未知符文槽抛出带槽位名的错误
8. 抽中的题目携带题目 id，并记录到该符文石的抽题记录中

## 验收标准

- [ ] 上述 8 条规则各至少一个用例，用例名使用领域术语（符文石、抽题、题池）
- [ ] 测试不依赖真实随机性：同一用例连续运行 20 次结果一致
- [ ] 人为删掉「避开其他符文石已抽走的题」这一逻辑，对应用例失败（验证后撤回，记在 Comments）
- [ ] 不修改抽题的生产代码；若某条规则无法在不改结构的前提下测试，在 Comments 记录并新建 prefactor 工单
- [ ] npm run check 全绿
