# 隐藏秘藏与 Python 彩蛋：给爱探索的玩家留一点惊喜

Status: needs-triage
Priority: P2
Source: 接手评估新增。现在每章野外的所有可交互物都在主路线上（碎片符文、祝福符文、石碑、封印门、传送门），探索没有回报；仓库里已有 CC0 素材 0x72 的宝箱开启动画（空箱 / 满箱 / mimic 三套帧，可自由再分发，当前版本未加载），正好可用。
Depends on: learning-records（彩蛋记录的持久化字段按存档 v3 扩展约定）；与 achievements-codex（秘藏/彩蛋可在图鉴中展示）、difficulty-economy（奖励不得与金币经济冲突）、accessibility（彩蛋文本可读）协调

## 问题陈述

- **玩家**：野外地图很大，但离开主路线什么也找不到；通关后「自由探索」也没有东西可探索。
- **爱折腾的学生**：Python 社区有大量文化梗（`import this`、`import antigravity`、`0.1 + 0.2 != 0.3`……），一款教 Python 的游戏却一个都没有，少了「会心一笑」的时刻。
- **教师**：彩蛋本身就是很好的知识点钩子（浮点误差、`__name__ == "__main__"`、`random_state` 可复现），但现在没有载体。
- **维护者**：想加探索内容时，没有「不影响主线进度、不影响题库规则、不影响跳章接缝」的道具类型可用。

## 解决方案

- **每章野外一处秘藏（共 11 处）**：藏在主路线之外，需要探索才能发现。草原风格章节用「幻影树」小径（看起来是树林，其实能穿过）；地牢风格章节用「裂纹墙」（挥剑可打开）。秘藏尽头是一个宝箱，按 E 打开前要答一道「秘藏题」。
- **秘藏题只用既有题池**（遵守 ADR-0001）：推荐取本章巢穴（lair）题池——tier 比碎片符文高一档，算「更难的题」；不新写题。
- **奖励不碰经济系统**：答对 → 宝箱打开、当场回满爱心、勇者获得本章秘藏的「星辉色调」外观（可在设置里切换），并在世界地图标题行显示「秘藏 x / 11」。
- **8 个 Python 文化彩蛋**散布在各章（见下表），触发后只有反馈与记录，不计入通关、不发碎片、不扣心。

### 彩蛋方案

| # | 彩蛋 | 位置 | 触发 | 反馈 |
| --- | --- | --- | --- | --- |
| 1 | `import this` | 第一章村庄一块小石碑 | 按 E 阅读 | 对话框逐句展示 Python 之禅（可选中英对照），末句后浮字「你领悟了 Python 之禅」 |
| 2 | `import antigravity` | 第三章高原一根羽毛 | 按 E 拾起 | 勇者浮空 3 秒（影子缩小、精灵上移，碰撞不变），浮字「import antigravity——你飞起来了！」 |
| 3 | `if __name__ == "__main__":` 之门 | 第二章函数之森角落一扇小门 | 走近 | 从本章正门（前一章传送门）进入时门开：「你被直接运行了，__name__ 是 \"__main__\"」；用世界地图快速传送进来时门不开：「你是被 import 进来的，__name__ 不是 \"__main__\"」 |
| 4 | `print("Hello, World!")` | 第一章出生点旁的告示牌 | 按 E | 告示牌冒出像素字「Hello, World!」——勇者的第一行程序 |
| 5 | `while True:` 史莱姆 | 第二章洞窟角落一只原地打转、头顶 `while True:` 的史莱姆（无伤害） | 挥剑 | 浮字「break」，它停下来乖乖消失 |
| 6 | `IndentationError` 碑 | 第三章一块歪斜的石碑 | 按 E 一次 / 两次 | 第一次：「IndentationError: unexpected indent」；第二次：石碑扶正，「缩进已修复 ✓」 |
| 7 | `0.1 + 0.2` 天平 | 第三章高原一座天平 | 按 E | 天平两盘 `0.1 + 0.2` 与 `0.3` 永远差一丝；对话解释浮点误差，最后一句 `np.isclose(0.1 + 0.2, 0.3)` 让天平平衡 |
| 8 | `random_state=42` 骰子 | 第十一章试炼场一颗石骰 | 按 E 多次 | 每次重开游戏按顺序掷出的点数序列都相同，浮字「random_state=42：同样的种子，同样的结果」（呼应 pj15 可复现性） |

> 彩蛋是 Python 文化与玩法，不是题面内容；但 #6、#7、#8 含知识性解释文字，措辞须在 grilling 中核对准确性（#8 呼应已上线题 pj15；#7 的浮点误差与 `np.isclose` 属通用 Python 常识，需确认是否与讲义口径一致）。

## 用户故事

1. 作为爱探索的玩家，我想要每章野外都藏着一处需要找一找才能发现的秘藏，以便离开主路线也有回报。
2. 作为玩家，我想要秘藏入口有若隐若现的线索（例如幻影树颜色略浅、裂纹墙有细小裂缝），以便靠观察而不是乱撞找到它。
3. 作为玩家，我想要石碑在本章通关后给一句关于秘藏方位的谜语提示，以便实在找不到时有线索可循。
4. 作为玩家，我想要打开宝箱前答一道比碎片符文更难的题，以便秘藏的奖励有分量。
5. 作为玩家，我想要秘藏题答错时和普通符文一样只扣 1 心且不会答死，以便规则一致、不被意外惩罚。
6. 作为玩家，我想要秘藏题在我答对之前保持同一道题，以便和符文石的抽题体验一致。
7. 作为玩家，我想要答对后宝箱播放开启动画、当场回满爱心，以便收获感明确。
8. 作为玩家，我想要每找到一处秘藏就解锁一种勇者「星辉色调」外观，并能在设置里切换，以便有可炫耀的收藏。
9. 作为玩家，我想要在世界地图标题行看到「秘藏 x / 11」，并在已找到秘藏的章节节点上看到小宝箱标记，以便知道还剩哪里没找。
10. 作为想专心学习的玩家，我想要秘藏和彩蛋完全可选、不影响通关和章节进度，以便不被分散注意力。
11. 作为玩家，我想要第一次触发彩蛋时有独特的反馈（浮空、天平、Hello World），以便会心一笑。
12. 作为学生，我想要 `0.1 + 0.2` 天平向我解释浮点误差，并告诉我该用 `np.isclose` 比较，以便在玩笑里学到真实的坑。
13. 作为学生，我想要 `__main__` 之门根据我「怎么进来」决定开不开，以便直观理解 `__name__` 的含义。
14. 作为学生，我想要 `random_state=42` 骰子每次掷出同样的序列，以便记住随机种子与可复现性的关系。
15. 作为玩家，我想要看到 Python 之禅时可以随时按 E 跳过，以便不被长文本困住。
16. 作为玩家，我想要彩蛋可以反复触发，但「已发现」记录只记一次，以便随时回来重温。
17. 作为玩家，我想要读档续玩后已找到的秘藏和已发现的彩蛋都还在，以便收集进度不丢。
18. 作为玩家，我想要「新的冒险」清档时秘藏与彩蛋记录一起清空，以便重新体验发现的乐趣。
19. 作为使用触控设备的玩家，我想要所有秘藏入口只靠移动和攻击就能打开，以便不需要额外按键。
20. 作为偏好减少动态效果的玩家，我想要浮空、天平摆动等效果在系统开启「减少动态效果」时变为静态展示，以便不引起不适。
21. 作为读屏用户，我想要彩蛋的反馈文字也出现在对话框里（而不只是浮字），以便能被朗读。
22. 作为维护者，我想要秘藏宝箱是独立的道具类型，跳章接缝把前序章节标记通关时不会顺带把秘藏标成已找到，以便 E2E 的进度断言不被污染。

## 实现决策

- **新道具类型 `chest`**（不复用 `rune`）：持有秘藏槽位 id `c{N}x`（第一、二章用手工命名，如 `secret1` / `secret2`），交互走与符文石同一条「抽题 → 答题面板 → 回调」路径，但回调只发秘藏奖励。跳章接缝只遍历 `rune` 类型，因此不会误标秘藏。
- **题池映射**：秘藏槽位映射到本章 `pools.lair`（缺省回退 `pools.heal`）。巢穴/祝福池现有占用：野外 2 块祝福 + 巢穴 3 块祝福 = 5 槽对 7 题，加秘藏后 6 槽对 7 题，仍满足「同池不撞题」；兜底规则（题池耗尽允许复用）保持不变。
- **秘藏是否已开**：直接由「已答槽位」集合推导（答对即开），**不新增存档字段**；「秘藏 x / 11」= 已答槽位中秘藏槽位的数量。
- **彩蛋记录**：新增存档字段 `eggs: string[]`（彩蛋 id 集合），按存档 v3 的扩展约定加入（依赖 learning-records 的 v3 schema 工单）；清档时一并清除；导出/导入随存档走。
- **外观**：「星辉色调」= 对勇者精灵叠加一层色调（Phaser tint），不需要新素材；当前选用的色调属于设置项，与 accessibility 的设置面板协调存放位置。
- **生成器放置**：通用生成器在 `forbidden` 之外再选一个远离中央十字路与出生点、贴近边界树林或地牢墙的格子作为秘藏点。草原风格：在该点外围补一圈树，留一棵「幻影树」（无碰撞体、色调略浅）作为入口；地牢风格：在墙上开凹室，入口为「裂纹墙」（有碰撞体，被挥剑命中后移除并播放碎裂特效）。第一、二章手工地图手动指定位置。
- **宝箱素材**：使用 CC0 0x72 的宝箱开启帧（满箱用于秘藏，mimic 帧可留给幻言魔像等其他 effort），经 vite 的公共素材目录在运行时加载；需核实帧尺寸与 4 倍显示比例下的清晰度。
- **彩蛋实现**：每个彩蛋是一个带 `egg` 字段的小道具或对已有道具的附加交互，反馈统一用对话框（可读屏）+ 可选浮字/动画；彩蛋 #3 需要知道「本次如何进入本章」，读取场景初始化时已有的出生点 key（`fromPrev` = 从正门进入；世界地图快速传送的出生点需核实）。
- **世界地图**：标题行在「已通关 x / N」后追加「秘藏 x / 11」；已找到秘藏的章节节点加一个小宝箱徽记（与现有锁/大头针徽记同族像素图标）。

## 测试决策

- **好测试的标准**：断言玩家可观察结果——宝箱开没开、爱心是否回满、地图计数、彩蛋反馈文本是否出现；不断言内部字段名。
- **E2E（首选）**：新增声明式步骤 `secretChest`：用 teleport 接缝走到生成器给出的秘藏入口 → 草原章节直接穿过幻影树 / 地牢章节挥剑打开裂纹墙 → 按 E 开箱 → 用现有答题助手答对 → 断言爱心满、已答槽位含秘藏槽、世界地图「秘藏 1 / 11」。彩蛋用 `easterEgg` 步骤（按 E 后断言对话框文本包含关键词）。先例：现有 collectShards / worldMap 步骤与 teleport 接缝。
- **smoke**：每章恰好一个 `chest`；秘藏槽位映射到本章题池；从出生点到秘藏入口存在不经过碰撞瓦片的路径（网格 BFS，幻影树视为可通行、裂纹墙视为可破坏）；秘藏槽位不在跳章接缝会标记的集合里。先例：smoke 的地图构建与「各章符文槽均指向本章题池」校验。
- **回归**：`gotoChapter` 后「秘藏 0 / 11」（未被误标）；`npm run check` 全绿。
