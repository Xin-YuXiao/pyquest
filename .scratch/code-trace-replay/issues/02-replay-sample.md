# 02: 回放样板：答对后「看它怎么跑」（单题打通）

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

选一道第二章的循环 / 函数题（如 d8 或 f12，以 01 号报告为准）打通全链路：

- prefactor：答题面板的代码块改为按行渲染（每行可单独加当前行标记），语法高亮逐行进行，四选一 / 填空外观不变。
- 答对可回放题后，解析区出现「▶ 看它怎么跑」；点开后代码块进入步进模式：当前行 ▶ 标记 + 底色，
  下方三栏（这一步 / 变量 / 已输出），控件上一步 / 下一步 / 开头 / 结尾，键盘 ←/→、Home/End。
- 轨迹数据按需动态加载（首次点击时才请求），加载中显示占位。
- 「领取奖励」随时可点，领取后回放面板随答题面板一起关闭。
- 答错时不出现回放按钮（spec 待决策 1 推荐项）。
- 接缝新增只读查询 `trace()`；如 E2E 需要确定性地抽到这道题，新增语义动作把指定题绑定到符文槽。
