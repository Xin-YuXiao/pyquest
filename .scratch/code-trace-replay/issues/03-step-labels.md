# 03: 每步中文解释标签 + 名词小贴士

Status: ready-for-agent
Type: task
Blocked by: 02

## 要做什么

回应 notional machine 批评：每一步都要有一句人话。

- 生成器用 `ast` 给每行标语句类型，结合事件类型与变量差分，按 spec 的模板表生成 `label`：
  新建变量、变量变化、可变对象原地变化、for 新一轮、循环结束、if 进入 / 跳过、调用（含实参）、返回（含返回值）、输出、异常。
- 模板表放在数据层（界面文案），生成器读取它；重新生成入库数据。
- 回放面板「变量」栏表头旁加一个「?」小贴士：用一两句话解释「变量表 / 局部变量 / 返回值」是什么。
- 当前步说明放入 aria-live 区域，读屏可听到。

## 验收标准

- [ ] 至少覆盖 for / while / if-else / 函数调用与返回 / print / 异常六类，各有一道题的轨迹里出现对应标签（报告列出示例）
- [ ] E2E：样板题步进时说明文字包含期望关键词（例如「for 循环第 2 轮」）
- [ ] 生成器自检：每一步 label 非空
- [ ] `npm run check` 全绿
