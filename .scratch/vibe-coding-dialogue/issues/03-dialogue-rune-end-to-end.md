## 要做什么

在题型扩展点上实现 `kind: 'dialogue'` 渲染器，用一条样板对话跑通全链路：

- 样板对话（W10 已确认考点 vc11 的对话化）：任务「写一个归一化的高斯函数」→ 玩家挑 prompt → AI 给出漏了 `1/(σ√(2π))` 的版本
  → 玩家选测试（峰值 x=μ=0、σ=2 应为 0.1995）→ 看到脚本化输出 1.0 → 打回并要求修正 → AI 给出正确版本 → 回归测试通过 → 接受 = pass；
  若玩家直接接受第一版 → fail 终点（解释「看起来对 ≠ 对」）。
- 仿聊天面板：任务目标、对话记录、四步进度条、选项（数字键可选）、「打字中」节奏可跳过、减少动态效果时整段出现、新消息读屏播报。
- 终点判定接入公共外壳：pass → 答对兑付；fail → 扣 1 心 + 显示该终点 explain + 「重新开始」；中途关闭不扣心、下次从头开始。
- 按 01 号决定放置这块对话符文（推荐 W10 巢穴、独立槽位与题池）。
- verify-quiz 覆盖样板对话里声明了输出的代码（漏系数版输出 1.0、正确版输出 0.1995）。
