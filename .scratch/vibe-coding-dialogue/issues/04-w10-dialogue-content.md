## 要做什么

按 01 号决定的首批范围（推荐 3 条），把 W10 成体系考点写成对话脚本：

- 测试先行：mag2flux 零点——先让玩家选「最能暴露零点错误的测试」（m=25 → 1.0），再让 AI 实现、用测试验收（对应 vc14）。
- 边缘情况：bin 边界 off-by-one 或除零 inf 污染（对应 vc13 / vc15），玩家需要主动补边界测试才能发现问题。
- 回归检查：v1 全绿 → 让 AI 加功能得到 v2 → 两条旧测试变红；正确处置是修回归或回退，「删测试 / 改期望值」走向失败终点（对应 vc17 / vc20）。

流程：agent 起草对话提纲（每条注明对应考点、通过路径、每个失败终点的教学点）→ 维护者 grilling 确认（W10 为零素材起草，需课程方过目）→ 录入。

## 验收标准

- [ ] `npm run check` 全绿
