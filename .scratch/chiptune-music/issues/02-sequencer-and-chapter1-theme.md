# 02: 序列器 + 第一章野外主题 + 答题压低（样板）

Status: resolved
Type: task
Blocked by: 01

## 要做什么

打通「主题数据 → 序列器 → 场景挂接 → 答题压低」整条链路，只做第一章：

- 序列器：低频定时器提前约 100ms 用 AudioContext 时钟调度音符；旋律（方波）、低音（三角波）、打击（噪声）三声部；以 16 分音符为步；曲目在小节边界淡入淡出切换。
- 主题数据为纯数据（动机、调式、速度、配器）；本工单只为第一章野外写一个主题，并实现「由参数展开成 8 小节循环」的生成规则。
- 进入第一章野外场景开始播放；离开到别的场景时淡出（其他章暂时无音乐）。
- 答题面板打开时音乐总线平滑压低到约 30%，关闭后恢复；对话框/世界地图打开时压低到约 60%。
- 测试接缝音频状态增加 track 与 ducked 字段。

## 验收标准

- [ ] 单元测试（依赖 core-unit-tests 的单元测试层；若尚未落地则以 smoke 的纯函数测试替代）：假时钟下 4 秒内调度的音符数与时间点符合 BPM 与乐段、无重复调度
- [ ] E2E：进入第一章野外后 track 为第一章野外主题；打开符文答题面板时 ducked 为真，关闭后为假；进入巢穴后音乐淡出（track 为空）
- [ ] 人工试听：样板主题录一段 30 秒的说明（或在 PR 描述中附试听步骤），供 03 grilling 使用
- [ ] 帧时间无明显回退（在第三章野外打开性能面板观察，或用 Playwright 采样 requestAnimationFrame 间隔，记录前后对比）
- [ ] npm run check 全绿
