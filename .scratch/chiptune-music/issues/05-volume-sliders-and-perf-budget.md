# 05: 音量滑块接入设置面板 + 性能预算

Status: ready-for-agent
Type: task
Blocked by: 02

## 要做什么

- 在设置界面提供「音乐音量 / 音效音量 / 静音」三项（若 accessibility 的设置面板已落地，作为其中的「声音」分组；否则先在标题画面提供一个最小声音设置弹层，形状与之对齐，日后合并）。
- 调节实时生效并持久化；音量为 0 时等价于该总线静音。
- 性能预算：在第三章野外（道具最多的生成图之一）测量开启音乐前后的帧间隔，写进 PR 描述；序列器单次调度回调的耗时不超过 1ms（在开发模式下打点验证）。
- 滑块对键盘和读屏可用（原生 range 输入或等价的 ARIA）。

## 验收标准

- [ ] E2E：把音乐音量调到 0 → 音频状态 musicVolume 为 0，刷新后保持；音效音量不受影响
- [ ] 滑块可用键盘调节（E2E 用方向键操作一次）
- [ ] 性能测量结果记录在 Comments
- [ ] npm run check 全绿
