## 要做什么

基于 02 号实测报告，与维护者逐条确认 spec「待决策」中的六项，把结论回填到 spec 的「实现决策」并在本工单 Comments 记录：

1. 代码符文是必经还是可选（推荐 v1 可选、巢穴祝福符文形态）
2. 提交未通过是否扣心（推荐扣 1 心，运行免费）
3. 判分默认模式（推荐 `asserts` + 数值容差）
4. 锁定的 Pyodide 版本（依 02 号数据）
5. 自托管还是 CDN（推荐自托管）
6. verify-quiz 是否加跑 Node 版 Pyodide（推荐加跑）

另需确认：代码符文的槽位位置（推荐 W6-W8 巢穴各 1 块，独立槽位与题池，tier 取该章 BOSS 档）。
