# 01: 答题面板题型分派 prefactor（四选一 / 填空之外的题型扩展点）

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

把答题面板拆成「公共外壳 + 题型渲染器」，为代码符文（本 effort）和对话符文（`vibe-coding-dialogue`）预留扩展点。
**玩家可见行为零变化**：现有四选一与代码填空题的外观、键盘操作（1-4 选项、Enter 确认）、扣心、
解析、「碎片入袋」兑付动画全部保持原样。

- 题目新增可选字段 `kind`，缺省视为 `choice`（四选一与 `fill` 填空都属于 `choice`）。
- 外壳负责章节标签、题干、反馈区、确认 / 取消、扣心、答对兑付与关闭；渲染器负责题面主体、作答交互、判定对错，
  通过统一回调把结果交回外壳。渲染器声明自己是否启用数字键 / Enter 快捷键。
- 未知 `kind`：smoke 直接报错；运行时兜底显示「此题暂不可用」，可关闭、不扣心。
- 题型注册表对外只暴露「按 kind 取渲染器」，新增题型不需要修改外壳。

## 验收标准

- [ ] 现有 251 题全部以 `choice` 渲染器呈现，人工抽查四选一与填空各 2 题，外观与交互与改造前一致
- [ ] 全部 11 章 E2E 不改任何断言原样通过（`npm run test:e2e`）
- [ ] smoke 新增校验：每题 `kind` 缺省或为已注册题型，未知 kind 报错（附一个反例自测：临时注入未知 kind 时 smoke 失败）
- [ ] 数字键 / Enter 快捷键只在 `choice` 题型生效（为后续文本输入题型铺路），由渲染器声明控制
- [ ] GLOSSARY 新增「题型（kind）」词条
- [ ] `npm run check` 全绿
