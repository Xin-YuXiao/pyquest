## 要做什么

实现 `kind: 'code'` 题型渲染器，并用**一道**题打通完整链路（建议改编 W6 已有的 nm7：dblquad 手算 2/3，
讲义确定输出，符合 ADR-0001）：

- 代码区：预填起始代码、待补全处醒目标出、Tab 缩进、行号、「重置代码」；获得焦点时暂停 Phaser 全局按键捕获，
  w/a/s/d/e/j/m/空格/方向键与 Enter、数字键都按文本输入处理。
- 「运行」显示 stdout / 报错（不扣心）；「提交」按 judge 判分：通过 → 走公共外壳的答对兑付（奖励类型由槽位决定），
  未通过 → 显示未通过的测试名并按 03 号规则扣心。
- 首次打开显示运行时加载进度；初始化失败 / 超时 → 切换到该题 `fallback` 四选一，顶部提示已降级，不扣心。
- 同一槽位答对前，关面板再开保留已写代码（会话内）。
- 按 03 号决定的位置放置这块代码符文（推荐 W6 巢穴，独立槽位与题池）。
- 数据层：smoke 校验代码题字段完整；verify-quiz 对代码题执行「参考解必过、起始代码必不过」。

## 验收标准

- [ ] E2E 新增步骤类型 `codeRune`：用真实键盘输入参考解（含 w/a/s/d/e/j/m 字母）→ 运行 → 看到期望输出 → 提交 → 奖励到账
- [ ] E2E 覆盖错误提交：扣 1 心、显示未通过测试名
- [ ] E2E 覆盖降级：`sandboxOffline()` 后打开代码符文出现四选一版本，答对正常发奖
- [ ] smoke：代码题字段完整性校验（含反例自测）
- [ ] verify-quiz：参考解通过、起始代码不通过（两者都在输出里列出）
- [ ] 输入代码期间角色不移动、不触发攻击 / 交互 / 静音
- [ ] `npm run check` 全绿（本地与 CI）
