# 02: 找 bug 题数据契约 + 构建期校验与预计算

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

不依赖任何具体题目内容，先把数据契约和校验器做出来：

- 定义 `kind: 'debug'` 的数据契约（spec「实现决策」形状）。
- 构建期脚本（复用 verify-quiz 的 python 探测与 UTF-8 设置）对每道找 bug 题执行四条规则：
  有 bug 代码至少一条测试失败；正确修复全部通过；每个非作弊错误修复至少一条失败；作弊选项只改测试不改代码。
  通过后预计算「bug 代码实际值」「修复后实际值」「每个错误修复的失败测试与实际值」，写入入库数据文件；CI 重新生成比对无差异。
- 用 2-3 道**不进入游戏的夹具题**（放在测试夹具里，不进题库）证明每条规则都能抓到违规。
- smoke 增加字段完整性检查（只对题库中存在的找 bug 题生效；现在为 0 道时检查空转通过）。

## 验收标准

- [ ] 夹具题覆盖四条规则的通过与违规情形，违规时脚本以非零退出并指出题号与规则
- [ ] 数值比较带容差（numpy 1.x/2.x 打印差异不影响结果）
- [ ] CI 同步检查接入 `npm test`；临时改夹具使其违规时 CI 失败（Comments 贴记录）
- [ ] `npm run check` 全绿
