# 01: 找 bug 符文规则拍板 + W10 首批改编稿确认

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

1. 和助教过一遍 spec「待决策」1、2、4、5，书面定稿。
2. 起草首批改编稿（可由 agent 起草，助教确认）：以 vc11 / vc12 / vc13 / vc15 / vc16 的情景为来源，每道写出
   「有 bug 的代码、3-4 条测试（期望值）、出错行、正确修复、2 个错误修复、1 个作弊选项、解析」。
   改编稿只使用原题已有的知识点与数值（例如高斯峰值 1/(2√(2π)) ≈ 0.1995、sin 30° = 0.5、linspace 边界数），
   并与 vibe-coding-dialogue 01 号对齐，避免同一情景在两种题型里重复。
3. 助教逐题确认 / 修改，结论记入 Comments，作为 03、04 号的内容输入。

## 验收标准

- [ ] spec 待决策 1、2、4、5 都有书面结论
- [ ] 至少 4 道改编稿获助教确认（未通过的写明原因）
- [ ] 每道改编稿注明来源题 id，且不引入原题以外的新知识点
- [ ] 与对话符文的情景分配表（哪个 bug 情景归哪种题型）确定
