# 02: 记录每一次符文石作答（答对 / 答错 / 放弃）

Status: resolved
Type: task
Blocked by: 01

## 要做什么

学生在任何符文石（碎片符文、祝福符文、BOSS 符文）上的每次作答都留下记录：
确认一个选项就记一条（对或错），打开面板后没作答就取消记一条「放弃」。
每道题的汇总（作答次数、错误次数、首答对错、最近一次结果、首次答对时间）随之更新，
并随自动存档写入 v3。

新增「学习记录」模块承担记录与汇总；答题面板只负责计时并在确认/取消时把作答事实交给它
（计时从面板打开到确认，页面隐藏期间暂停，单次上限 30 分钟）。

## 验收标准

- [ ] 记录字段齐全：时间、题 id、槽位 id、符文类型（shard/heal/boss）、章/题池/tier 快照、
      选项下标、对错（1/0/-1 放弃）、用时毫秒、该题第几次尝试
- [ ] 同一次打开面板内连错两次再答对：三条记录，尝试序号 1、2、3，汇总 n=3、w=2、first='w'
- [ ] 换一块符文石再遇到同一道题时，尝试序号继续累计
- [ ] 「放弃」不计入尝试次数，单独计数
- [ ] 切到后台 5 秒再回来作答，用时不包含后台时间（E2E 可用页面可见性模拟，或单元测试覆盖计时器）
- [ ] E2E runner 新增步骤类型：真实点击一个错误选项后再答对；在至少一个章节脚本中使用，
      断言心数 −1、`state().records` 中出现错误记录与正确记录
- [ ] 单元测试覆盖汇总更新规则（首答、错误计数、solvedAt 只写一次）
- [ ] 现有全部章节 E2E 不受影响；`npm run check` 全绿
