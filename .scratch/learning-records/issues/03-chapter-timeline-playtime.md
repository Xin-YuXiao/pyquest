# 03: 章节时间线与有效游玩时长（修正胜利画面「冒险用时」）

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

每章记下三个时间点（首次进入野外、打开封印门、通关），只记第一次发生；
同时累计「有效游玩时长」——页面在前台时计时，关掉游戏或切后台的时间不算。

胜利画面的「冒险用时」改用有效游玩时长。现状是「当前时间 − 首次开始时间」，
读档续玩会把关掉游戏的几天也算进去。

## 验收标准

- [ ] 首次进入某章野外写 `enteredAt`；打开封印门写 `gateOpenedAt`；击败 BOSS 写 `doneAt`；重复发生不覆盖
- [ ] 世界地图快速传送回已通关章节不改写已有时间点
- [ ] 有效游玩时长随存档持久化；读档后继续累加而不是重置
- [ ] 页面隐藏期间不累加（单元测试用可控时钟覆盖；E2E 用页面可见性模拟抽查）
- [ ] 胜利画面用时显示有效游玩时长；E2E 在胜利后断言该章 `doneAt` 已写入且 `playMs` > 0
- [ ] 测试接缝的语义动作 gotoChapter 跳章时，前面各章的时间点保持 null（不伪造时间）
- [ ] `npm run check` 全绿
