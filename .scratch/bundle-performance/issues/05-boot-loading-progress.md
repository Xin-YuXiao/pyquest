# 05: 标题画面加载进度，素材就绪前「开始冒险」不可误点

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

学生打开游戏时，标题画面显示素材加载进度。加载完成前，「开始冒险」「新的冒险」按钮处于禁用状态，文案为「加载中 N%」；加载完成后恢复正常文案并可点击。某个素材加载失败时，显示「加载失败」提示和「重试」按钮（点击后重新加载页面）。

背景：标题画面是页面里的静态 HTML，一开始就显示「开始冒险」，但点击处理要等素材全部加载完、启动场景进入 create 阶段才绑定。网速慢时点了没有反应。请先在节流网络下实测确认这一现象，把结果记在 Comments。

做法：

- 启动场景的预加载阶段通过页面自定义事件报告进度和失败，与 HUD 刷新事件同一模式。
- 标题模块根据这些事件更新按钮状态和进度显示。
- 测试接缝新增只读查询「启动是否就绪」。
- 进度条在减少动态效果偏好下不使用过渡动画。

## 验收标准

- [ ] 节流网络下的现状实测结果（点击无反应持续多久）记录在 Comments
- [ ] 加载期间按钮禁用且显示百分比；完成后自动恢复可点击，无需刷新
- [ ] E2E：拦截并延迟素材响应时，断言按钮禁用且进度可见；放行后断言按钮可用
- [ ] E2E：拦截一个素材请求使其失败时，断言失败提示与重试按钮出现
- [ ] 测试接缝的「启动是否就绪」查询写进接缝模块的文档注释，runner 在新游戏步骤里使用它
- [ ] 有存档时，「继续冒险 · 第 N 章」的文案在加载完成后正确显示
- [ ] npm run check 全绿
