# 03: 课题符文按序解锁（链 id + 步号）

Status: resolved
Type: task
Blocked by: 02

## 要做什么

实现「第 N 块在第 N-1 块解开前封印」的通用能力，并在秘境骨架里用占位题演示：

- 符文道具新增可选字段「所属链 id + 步号」；交互时若上一步槽位未破解：不开题，浮字提示「先完成：<上一步名称>」。
- 已解开的课题符文照旧置灰；未轮到的课题符文有可区分的视觉（如暗淡 / 锁形标记），靠近时的交互提示同步改为「需先完成上一步」。
- 课题符文答对回 1 心、不产碎片；答错扣 1 心（沿用「最多扣到 1」）。
- 进度推导：第 N 步完成 = 该步槽位已破解；只读查询 `trials()` 返回每个 Project 的已完成步数（不新增存档字段）。
- 道具契约文档（PropDef 说明）补充新字段。

## 验收标准

- [ ] E2E：直接交互第 3 块课题符文时不开题并出现提示；按 1→6 顺序可依次开题
- [ ] E2E：完成 2 步后刷新页面，`trials()` 仍报告 2 步，第 3 块可交互、第 4 块仍封印
- [ ] 主线章节的符文行为不受影响（11 章 E2E 原样通过）
- [ ] smoke：同一链的步号从 1 连续编号、无重复
- [ ] `npm run check` 全绿
