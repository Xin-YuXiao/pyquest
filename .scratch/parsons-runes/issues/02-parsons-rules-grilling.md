# 02: 拼图符文产品规则拍板

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

和助教 / 课程负责人过一遍 spec「待决策」并定稿，结论写回 spec 与本工单 Comments：

1. 槽位形态：独立拼图符文（推荐：W1-W3 野外各 1 块，祝福符文形态，答对回心不产碎片）还是现有符文随机呈现为拼图；
2. 扣心规则：与四选一一致（推荐）还是前两次错不扣；
3. 反馈粒度：行级反馈（推荐）；
4. 干扰行：v1 不做（推荐），v2 是否立项走提纲；
5. 首批范围与顺序：W2 → W1 → W3（推荐），以及从 01 号报告里挑出首批 3-5 道具体题目（由助教确认这些题适合做拼图）。

## 验收标准

- [ ] 五个问题都有书面结论（采用推荐 / 改为某方案 + 理由）
- [ ] 首批拼图题 id 清单确定（基于 01 号生成器报告）
- [ ] spec 的「待决策」更新为「已决策」，Status 改为 ready-for-agent（若整体通过）
