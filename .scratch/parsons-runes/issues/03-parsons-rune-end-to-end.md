## 要做什么

在 W2 野外放一块拼图符文，走通「开面板 → 拖 / 键盘排行 → 提交 → 判定 → 奖励」全链路：

- 题库新增 02 号确定的首批 W2 拼图条目（`kind: 'parsons'`，`from` 引用来源题，独立题池，tier 取 W2 野外档）；
  章节配置与地图生成器新增对应槽位（按 02 号决定的形态）。
- 经题型分派注册拼图渲染器：卡片列表 + 缩进刻度；Pointer Events 拖动（触屏可用）；
  键盘 ↑/↓ 焦点、Space 拿起 / 放下、拿起后 ↑/↓ 移动 / ←/→ 缩进、Enter 提交。
- 判定查 01 号的合法排列数据；答对 → 原题解析 + 按槽位形态发奖励；答错 → 按 02 号规则扣心。
- 固定种子打乱（符文槽 id + 题 id），保证同一符文石重开顺序不变、初始排列不是合法排列；答对前的排列在会话内保留。
- 接缝新增只读查询 `parsons()`（当前顺序 / 缩进 / 一个合法排列）。
