# 04: 答错时的行级反馈

Status: needs-info
Type: task
Blocked by: 03

## 要做什么

排错提交后，标出「第一处放错的行」：在全部合法排列里找与玩家排列最长公共前缀最长的一个，
把第一处不一致的那一行加上错位标记（图标 + 文字「这一行的位置 / 缩进不对」，不只靠颜色），
不透露它应该去哪里。缩进错与顺序错用不同文字区分。玩家移动任意一行后标记消失。

## 验收标准

- [ ] E2E：故意交换两行提交 → 标记出现在正确的行上；只改缩进提交 → 文字提示为「缩进」
- [ ] 标记逻辑是纯函数，在 smoke（或单元测试层，若已落地）里用夹具覆盖：顺序错、缩进错、多个合法排列取最近者
- [ ] 读屏可读到错位提示（与 accessibility 的 aria-live 约定一致，若其已落地）
- [ ] `npm run check` 全绿
