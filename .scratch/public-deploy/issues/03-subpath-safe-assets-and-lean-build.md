# 03: 资源路径相对化 + 构建产物只含实际加载的素材

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

让构建产物能放在任意静态托管的任意子路径下正常运行，且不夹带未用文件：

- 素材清单里的资源 URL 不再写死根绝对路径，统一相对构建 base 解析（Tiny Swords 与 CC0 同理）；
- 构建产物里的素材文件 = 素材清单实际引用的文件：未加载的 `assets/cc0` 不进产物；
- 本地开发（`npm run dev`）与现有 E2E 行为不变。

## 验收标准

- [ ] 新增子路径回归：把构建产物挂在本地静态服务的 `/pyquest/` 路径下，跑一条最小 E2E（标题页 → 开始冒险 → 第一章野外 → 打开一块碎片符文），无 404、浏览器无报错（占位素材环境下即可运行）
- [ ] 新增产物清单检查：构建后比对产物素材文件与清单引用文件，多 / 少都失败；接入 CI
- [ ] 构建产物体积较改动前减少（记录前后数字到 Comments）
- [ ] 现有 11 章 E2E 原样通过；`npm run check` 全绿
