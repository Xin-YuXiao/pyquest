# 06: 发布流水线：主分支自动部署 + 线上冒烟

Status: needs-info
Type: task
Blocked by: 01, 02, 03, ../self-hosted-fonts/issues/01

## 要做什么

按 01（素材方案）与 02（托管平台）的结论实现自动发布：

- 新增只在主分支运行的部署作业，依赖现有 lint / test / build / test:e2e 全绿；
- 方案 A：从 CI 私有存储取 Tiny Swords 素材用于部署构建，日志与制品中不泄露下载地址；仓库与 PR 构建仍用占位图；
- 部署到选定平台；若有预览环境，PR 构建部署到预览地址并在 PR 上给出链接（是否同源按 02 结论处理存档键）；
- 部署后对线上地址跑最小冒烟（标题页出现 → 开始冒险 → 第一章野外 → 打开一块碎片符文 → 关闭），失败则作业失败；
- README 增加「在线游玩」链接与发布说明（如何回滚：重新部署某个提交）。

## 验收标准

- [ ] 合并到主分支后自动部署成功，线上冒烟通过
- [ ] 线上页面字体与素材全部来自本站（无 Google Fonts / jsdelivr 请求，依赖 self-hosted-fonts）
- [ ] 线上页面标题页显示的版本串与部署提交一致（依赖 04，若未落地则跳过此项并注明）
- [ ] 仓库内仍无 Tiny Swords 素材文件；CI 日志中无素材下载凭据
- [ ] 回滚演练一次（重新部署上一个提交）并记录到 Comments
- [ ] 部署作业以 CI 的 `npm run check` 全绿为前置条件（检查不过不发布）
