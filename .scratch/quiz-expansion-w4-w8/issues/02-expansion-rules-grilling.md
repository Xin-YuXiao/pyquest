# 02: 扩充目标与规则拍板（题量、三池比例、拓展题、符文数量、批次）

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

与维护者（必要时含课程方）逐条确认 spec「待决策」五项，结论回填 spec 并在 Comments 记录：

1. 每章目标题量：40（推荐）还是 60
2. 三池比例：保持 10/7/3（推荐，40 题 = 20/14/6）还是按抽取频率 3:5:1
3. 是否允许讲义外的「拓展」题（推荐不允许；若允许需新增 ADR 取代 ADR-0001 的相应部分）
4. 是否同时增加符文数量（推荐不增加——单次通关仍抽 9 题，多练交给复习模式）
5. 批次顺序（推荐批次 A：W4+W5 与批次 B：W6-W8 并行）

会前要让参会者知道：单次通关只抽 9 题，扩充的直接收益是「同学之间题目不同 + 重玩新鲜 + 复习题源」，不是「一次通关多练」。

## 验收标准

- [ ] 五项均有结论写入 spec，「待决策」清空或标注已决
- [ ] 若决定允许拓展题：新增 ADR（编号顺延）并在 ADR-0001 标注被部分取代
- [ ] 结论里给出每章每池的目标题量表（04 号提纲直接使用）
