# 03: 可打印的学习报告页 + 游戏内入口

Status: needs-info
Type: task
Blocked by: 01, 02

## 要做什么

学生在胜利画面或世界地图点「学习报告」，新标签页打开报告页：读取本机存档，用 02 的统计模块渲染
总览、分章表、薄弱点（附「去错题本复习」提示）、通关时间线、底部指标说明与「数据只来自本机」声明。
顶部可选填姓名/学号（不写入游戏存档）。浏览器打印时版面整洁（隐藏按钮、分页合理）。
报告页不加载游戏引擎；构建产物里报告页是独立入口。

## 验收标准

- [ ] 胜利画面按钮区与世界地图头部各有「学习报告」入口，新标签页打开
- [ ] E2E：第一章（其中一题先答错）通关后打开报告 → 第一章行存在、首答正确率 < 100%、薄弱点包含该题知识点
- [ ] E2E：无存档时打开报告页显示引导文案，无浏览器报错
- [ ] 姓名/学号不出现在游戏存档里（E2E 断言存档内容）
- [ ] 打印样式：打印预览中不出现按钮与输入框边框（截图人工检查一次，结果记录在 Comments）
- [ ] 生产构建包含报告页入口，报告页体积不包含游戏引擎（构建产物检查）
- [ ] `npm run check` 全绿
