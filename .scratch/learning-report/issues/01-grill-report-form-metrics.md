# 01: 拍板报告形态、指标口径与班级汇总

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

和维护者/课程方确认 spec「待决策」四条，结论写回 spec「实现决策」：

1. 独立报告页 vs 游戏内覆盖层（推荐独立页面）
2. 是否做班级汇总视图（推荐做，本地拖拽）
3. 姓名/学号是否必填（推荐选填）
4. 指标口径——首答正确率、总正确率、用时取中位数、薄弱点阈值（作答 ≥ 3 次）是否符合课程评价习惯

## 验收标准

- [ ] 四条都有结论并写入 spec（含理由）
