# 05: 班级汇总视图（老师本地拖入多份 JSON）

Status: needs-info
Type: task
Blocked by: 01, 04

## 要做什么

报告页的「汇总」视图：老师选择或拖入多份学生导出的 JSON，逐个校验（format、reportVersion、integrity），
按学号（无则姓名，再无则文件名）去重并提示重复，输出全班分章表（人数、平均首答正确率、通关人数）
与全班最常错的知识点，可下载汇总 CSV。全部在本地浏览器计算，不上传。
无法读取 / 版本不符 / 校验未通过的文件逐个列出原因，不影响其余文件。

## 验收标准

- [ ] 单元测试：汇总函数对 3 份构造报告（含 1 份重复、1 份 integrity 不通过）给出正确结果与提示
- [ ] E2E：汇总视图上传 3 份 JSON 文件 → 表格行数、重复提示、校验失败提示正确；下载汇总 CSV 内容正确
- [ ] 不发出任何网络请求（E2E 中拦截并断言外部请求为 0）
- [ ] `npm run check` 全绿
