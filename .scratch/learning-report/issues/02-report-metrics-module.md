# 02: 报告统计口径模块（纯函数 + 单元测试）

Status: ready-for-agent
Type: task
Blocked by: ../learning-records/issues/02, ../learning-records/issues/03

## 要做什么

一个不依赖页面与游戏引擎的统计模块：输入 v3 存档对象与当前题库，输出报告数据对象
（总览、分章表、薄弱点、时间线、主线/复习分开统计），口径严格按 spec「实现决策」。
本工单没有界面，用单元测试证明每个数字的算法；后续报告页、导出、汇总都只消费它的输出。

## 验收标准

- [ ] 首答正确率、总正确率、用时中位数、作答题数按 spec 定义计算；放弃不计入
- [ ] 复习作答不计入首答正确率，单列复习次数与复习正确率
- [ ] 薄弱点：作答 < 3 次不参与排名，按错误率降序取前 5，知识点与题池分别给出
- [ ] 章归属使用记录中的章快照；题库中已不存在的题仍计入统计，摘要显示「题目已更新」
- [ ] 已通关但无记录、时间点为 null 的章标记为「升级前的记录不可用」
- [ ] 空存档 / 无作答时返回全零且带「暂无数据」标记，不抛异常
- [ ] 单元测试覆盖以上每一条（构造 v3 存档样本）
- [ ] `npm run check` 全绿
