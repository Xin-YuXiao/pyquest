# 03: 错题本列表（世界地图入口 + 筛选）

Status: resolved
Type: task
Blocked by: 01, ../learning-records/issues/02

## 要做什么

世界地图（Tab）头部出现「错题本（N）」按钮，N = 曾错且未掌握的题数（没有错题时显示 0）。
点开是一层叠在世界地图之上的面板：按章分组列出所有曾答错的题，每行显示题面摘要、知识点标签、
错误次数、最近一次对错、复习进度；顶部可按章、符文类型（碎片/祝福/BOSS）、知识点筛选；
分「待复习」「已掌握」两个页签；为空时显示友好提示；当前题库中已不存在的题显示「题目已更新」且不可点开。

本工单只做只读列表（复习作答在 04）。

## 验收标准

- [ ] E2E：第一章在符文石上先答错一次再答对 → Tab 打开世界地图 → 按钮显示「错题本（1）」→ 列表包含该题与「错 1 次」
- [ ] E2E：没有错题时按钮显示 0，打开后显示空状态提示
- [ ] 筛选：章 / 符文类型 / 知识点三组筛选可组合，结果正确（单元测试覆盖筛选函数）
- [ ] 题库中不存在的题 id 显示「题目已更新」、不计入 N（单元测试构造一个假 id）
- [ ] 答题面板或对话框打开时无法打开错题本；关闭错题本回到世界地图
- [ ] 测试接缝新增只读查询 `mistakes()`
- [ ] `npm run check` 全绿
