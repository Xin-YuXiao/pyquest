# 05: 「再练一组」连续复习与小结

Status: needs-info
Type: task
Blocked by: 04

## 要做什么

错题本顶部「再练一组」按钮：从待复习题中按「错误次数降序 → 最近错误时间降序」取最多 5 道，
依次以复习模式作答，每题答完点「下一题」；最后一题后显示小结（答对 x / 总数、新掌握 y 道）。
中途取消即结束本组，已作答的结果保留。待复习题为 0 时按钮禁用。

## 验收标准

- [ ] 单元测试覆盖取题排序规则与「不足 5 道时全取」
- [ ] E2E：通过真实答错制造至少 6 道错题 → 再练一组 → 只出 5 道 → 作答完看到小结，数字与实际作答一致
- [ ] E2E：组内第 2 题时取消 → 回到错题本，第 1 题的结果已保留
- [ ] 待复习为 0 时按钮禁用
- [ ] `npm run check` 全绿
