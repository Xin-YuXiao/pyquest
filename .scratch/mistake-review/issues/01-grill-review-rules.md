# 01: 拍板复习规则（扣心 / 掌握阈值 / 知识点粒度 / 入口）

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

和维护者/课程方过一遍 spec「待决策」五条，把结论写回 spec 的「实现决策」并删掉对应待决策条目：

1. 复习是否扣心（推荐不扣）
2. 掌握阈值 N（推荐连续答对 2 次）
3. W4-W11 是否补细分知识点标签、由谁按讲义命名（推荐补，单独做题库元数据批次）
4. 标题画面是否也放错题本入口（推荐不放）
5. 首版是否做基于日期的到期复习（推荐不做）

## 验收标准

- [ ] 五条都有明确结论并记录在 spec 中（含理由）
- [ ] 若第 3 条结论为「补」，新建一个题库元数据 effort 或工单，并注明它走 ADR-0001 的确认流程
- [ ] 本 effort 中 Status 为 needs-info 的工单改为 ready-for-agent
