# 02: 答题面板支持「复习模式」（prefactor）

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

让答题面板在打开时接收一个模式：主线模式行为与现在完全一致；复习模式下答错不扣心、
答对不执行奖励回调（不产碎片、不回心、不破盾、不写已破解槽位）、答对答错都展示解析、
选项按随机排列展示并在判定时映射回原始下标（填空题照常把选项文本填入空槽）。

本工单只做答题面板这一层与它的测试，不做错题本界面。需与 `../pyodide-sandbox/issues/01`
（答题面板题型分派）兼容：两者谁先落地，后做的在其基础上扩展，不各写一套分支。

## 验收标准

- [ ] 主线模式下全部现有章节 E2E 保持全绿（行为零变化）
- [ ] 复习模式下答错：心数不变、提示与解析出现、可以换选项再试
- [ ] 复习模式下答对：碎片/心数/已破解槽位/已答对题目/抽题记录全部不变
- [ ] 选项打乱：展示顺序随机，键盘 1-4 与点击都按展示顺序选择，判定结果正确；填空题正确填词
- [ ] 单元测试覆盖展示下标 ↔ 原始下标映射（含填空题）
- [ ] 测试接缝提供一个只读方式确认当前面板模式（或通过可见 UI 区分），供后续 E2E 使用
- [ ] `npm run check` 全绿
