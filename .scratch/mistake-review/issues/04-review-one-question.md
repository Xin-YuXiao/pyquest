# 04: 复习一道错题（掌握规则 + 记录）

Status: resolved
Type: task
Blocked by: 01, 02, 03

## 要做什么

在错题本里点一道题，用复习模式的答题面板作答。复习作答写入学习记录（符文类型记为 review），
并更新这道题的复习状态：连续答对达到阈值（推荐 2 次）→ 移到「已掌握」；复习答错 → 连续计数清零，
已掌握的题若复习答错退回「待复习」。主线状态（碎片、心、符文石、已答对题目）全部不变。

## 验收标准

- [ ] E2E：复习该题先答错（心数不变）→ 再答对（碎片不变、解析出现）→ 该题复习进度 1/2
- [ ] E2E：再复习一次答对 → 移到「已掌握」，错题本按钮数字减 1
- [ ] E2E：刷新页面后复习状态保留（随 v3 存档持久化）
- [ ] 复习记录在 `state().records` 中可见，符文类型为 review、槽位为空
- [ ] 单元测试覆盖掌握规则状态转换（含已掌握后答错退回）
- [ ] `npm run check` 全绿

## Comments
