# 03: 心之容器：爱心上限成长与老存档补发

Status: needs-info
Type: task
Blocked by: 01, ../learning-records/issues/01

## 要做什么

- 按 01 定稿的节奏，在通关指定章节时发放心之容器，爱心上限 = 6 + 已获得容器数；获得时有提示（胜利页统计或浮字）；
- 爱心上限超过一行容量时 HUD 切换为紧凑显示，在 960 设计宽度内不溢出、竖屏不遮挡；
- 读档时对老存档按已通关章节补发容器并重算上限；
- 死亡重生仍回满到当前上限。

## 验收标准

- [ ] 单元测试：给定已通关章节集合，容器数与爱心上限符合配置
- [ ] E2E：通关发放容器的那一章后，`state().maxHearts` 增加，HUD 爱心数相应增加
- [ ] E2E：构造一个已通关多章的老存档（v2 或 v3 无 economy 字段），读档后上限按规则补齐
- [ ] 上限达最大值时 HUD 截图在 960×640 与 390×844 视口下均无溢出（截图留存到 E2E 截图目录）
- [ ] `npm run check` 全绿
