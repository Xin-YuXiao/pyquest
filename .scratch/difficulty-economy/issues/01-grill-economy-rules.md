# 01: Grilling：敲定爱心成长、金币、商店、提示卡与难度档位规则

Status: ready-for-human
Type: grilling
Blocked by: None (can start immediately)

## 要做什么

这是玩法改动，必须先由维护者（必要时与课程方）拍板。逐条过 spec「待决策」1-7，每条记录最终决定与理由，并把确定的数值填成一张「经济配置表」（来源、数额、价格、档位参数、按章递增系数）。

议程：

1. 爱心上限成长规则与上限值
2. 金币来源与数额（首答正确 / 非首答 / 小怪 / BOSS）
3. 商店道具清单、价格、商人位置
4. 提示卡的边界（排除几个选项、BOSS 符文是否禁用、是否影响「首答正确」判定）
5. 是否引入难度档位，三档各自的参数
6. 是否按章递增小怪 / BOSS 强度，从哪章开始、幅度多大
7. 「猜答案零成本」是否需要额外机制

## 验收标准

- [ ] 7 个议题各有明确决定，写在本工单 `## Answer` 下
- [ ] 经济配置表定稿（可直接被后续工单照抄实现）
- [ ] 若决定与 spec 推荐不同，同步更新 spec 的实现决策
- [ ] 决定后把 02-06 中仍适用的工单 Status 改为 ready-for-agent，不再适用的改为 wontfix 并注明原因
