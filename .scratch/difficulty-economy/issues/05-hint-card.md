# 05: 提示卡：排除一个错误选项

Status: needs-info
Type: task
Blocked by: 04, ../pyodide-sandbox/issues/01, ../learning-records/issues/01

## 要做什么

- 答题面板在持有提示卡时显示「使用提示卡」按钮（BOSS 符文上隐藏或禁用，按 01 决定）；
- 使用后确定性地移除一个错误选项（以题目 id + 槽位为种子，关闭再打开面板结果不变），提示卡 -1；
- 作答记录标记本次「用过提示」；是否仍算首答正确按 01 决定；
- 讲解照常展示；数字键 1-4 映射到剩余选项的显示顺序，键盘与触屏都能用。

## 验收标准

- [ ] E2E：持有提示卡时在碎片符文上使用，选项数从 4 变为 3，被移除的一定是错误选项
- [ ] E2E：关闭面板后再打开，同一道题的被移除选项不变
- [ ] E2E：BOSS 符文上提示卡不可用
- [ ] 单元测试：排除选项的确定性与「永不移除正确选项」
- [ ] 作答记录中该次作答带「用过提示」标记（通过只读状态断言）
- [ ] `npm run check` 全绿
