# 04: 商人与商店：回复药水与护心符

Status: needs-info
Type: task
Blocked by: 02

## 要做什么

- 在 01 决定的位置放置商人（推荐每章野外引导石碑旁）；靠近按交互键打开商店浮层；
- 商店浮层列出道具名称、效果说明、价格、持有数与当前金币；余额不足时购买按钮禁用并说明原因；
- 回复药水：在自由探索时使用（使用入口按 01 决定：商店内立即使用 / HUD 道具栏），满血时不可用；
- 护心符：持有时答错不扣心并消耗一个，答错反馈文案提示「护心符抵挡了伤害」；
- 浮层是模态对话框（若 `accessibility/issues/01` 已落地，遵守同一焦点规则）。

## 验收标准

- [ ] E2E：金币足够时购买回复药水，金币减少、持有数 +1；金币不足时按钮禁用
- [ ] E2E：持有护心符时答错一题，爱心不变、护心符 -1
- [ ] 单元测试：购买校验（余额、上限）与道具效果规则
- [ ] 商人不挡住符文石、封印门、传送门（smoke 数据层校验商人坐标与这些要素的最小间距）
- [ ] `npm run check` 全绿
