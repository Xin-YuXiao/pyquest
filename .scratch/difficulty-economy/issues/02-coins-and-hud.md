# 02: 金币：发放规则、HUD 显示与存档

Status: needs-info
Type: task
Blocked by: 01, ../learning-records/issues/01, ../core-unit-tests/issues/01

## 要做什么

- 按 01 定稿的配置实现金币发放：首答正确的符文石、击败小怪（掉落拾取或直接入账，按 01 决定）、击败 BOSS；
- 「首答正确」从作答记录判定，不另建记录；
- HUD 在碎片计数旁显示金币，获得时有轻量跳变反馈（遵守减少动态效果判定，若 `accessibility` 已落地）；
- 存档追加 economy 可选字段并默认补齐；「新的冒险」清零。

## 验收标准

- [ ] 单元测试覆盖金币发放规则的全部分支（首答 / 非首答 / 小怪 / BOSS / 答错不扣）
- [ ] E2E：第一章首次即答对一块碎片符文后，`state()` 中金币按配置增加；先答错再答对的符文不给（或按配置少给）
- [ ] E2E：刷新读档后金币保留；新的冒险后为 0
- [ ] 不含 economy 字段的 v3 存档能正常读取（默认补齐）
- [ ] `npm run check` 全绿
