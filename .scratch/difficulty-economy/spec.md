# 难度曲线：爱心成长、金币与商店

Status: needs-triage
Priority: P2
Source: upstream README 路线图「难度曲线（爱心上限 / 商店金币）」；接手评估补充（源码核实的现状与「猜答案零成本」问题）
Depends on: learning-records（存档字段与作答记录）、core-unit-tests（规则函数的单元测试）

## 问题陈述

现在十一章的难度几乎是一条平线，而且奖惩对学习没有引导作用（源码核实）：

- 爱心上限固定 6，整局不成长；
- 答错扣 1 心，但**最低留 1 心**，答题永远不会致死；同一块符文石在答对前始终是同一道题——
  于是「把四个选项挨个试一遍」的成本几乎为零，学生可以不读题硬猜过关；
- 小怪接触伤害 1 心并会致死，死亡后回本章野外重生、爱心回满、进度保留——惩罚只是位置重置；
- 小怪只有两种（红小兵 hp 2、黑勇士 hp 3），数量与种类由章节主题配置，**不随章节 / tier 增强**；
  BOSS 血量在各章相同（史莱姆系 10、巨蟒系 12）；
- 回血来源只有祝福符文（+1 心）与小怪 22% 概率掉落的爱心；
- 没有任何货币、商店或可选的辅助道具；首答正确与试错过关在奖励上没有区别。

对教学游戏来说，这既让后期章节缺乏挑战，也让「认真读题、一次答对」得不到额外回报。

## 解决方案

在不削弱学习目标的前提下引入一条温和的成长与经济线（具体规则由 01 grilling 拍板，下面是推荐方案）：

- **心之容器**：每通关两章获得一个，爱心上限 6 → 最多 11；
- **金币**：首次作答即正确的符文石给金币（主要来源），击败小怪与 BOSS 给少量金币；试错后才答对的不给（或少给）；
- **商店**：在村庄 / 各章引导石碑旁开设商人，出售回复药水、「护心符」（下一次答错不扣心）、「提示卡」（排除一个错误选项，BOSS 符文禁用）；
- **难度档位**：轻松（小怪不造成接触伤害，专注学习）/ 标准（默认）/ 挑战（小怪随章增强、答错扣 2 心）；
- **按章递增**：标准档下后期章小怪血量与速度小幅提高，BOSS 血量小幅提高。

## 用户故事

1. 作为学生，我想在认真读题、第一次就答对时得到金币奖励，以便感受到「读懂再答」比瞎猜更划算。
2. 作为学生，我想在试错后才答对时仍能拿到碎片，但金币更少或没有，以便规则公平又不劝退。
3. 作为学生，我想在通关章节后获得心之容器、爱心上限提升，以便感到角色在成长。
4. 作为学生，我想在 HUD 上看到金币数量，并在获得时有轻量反馈，以便知道自己的积累。
5. 作为学生，我想在商人处用金币买回复药水，以便在巢穴 BOSS 战前补血。
6. 作为学生，我想买一张提示卡在难题上排除一个错误选项，以便卡住时有台阶下而不是瞎猜。
7. 作为学生，我想让提示卡不能用在 BOSS 符文上，以便章节综合题仍检验真实理解。
8. 作为学生，我想用了提示卡后仍能看到完整讲解，以便把题真正弄懂。
9. 作为学生，我想买护心符抵消下一次答错的扣心，以便在不熟悉的章节放心尝试。
10. 作为只想学习、不擅长动作游戏的学生，我想选择「轻松」档让小怪不伤人，以便专注答题。
11. 作为想要挑战的学生，我想选择「挑战」档让后期章节更难，以便获得成就感。
12. 作为学生，我想在标准档下感受到后期章节的小怪更强一点，以便难度和课程进度同步爬升。
13. 作为学生，我想让金币、道具、爱心上限和难度档位随存档保存、读档后恢复，以便中断后继续。
14. 作为学生，我想在「新的冒险」后金币和道具清零，以便重新开始是真正的重新开始。
15. 作为老存档玩家，我想升级后读档时自动获得与已通关章节相符的心之容器，以便不吃亏。
16. 作为学生，我想在商店里看到每件道具的价格、效果说明和我还剩多少金币，以便做决定。
17. 作为学生，我想在金币不够时看到明确提示而不是什么都不发生，以便理解原因。
18. 作为学生，我想让爱心上限提升后 HUD 不会挤爆或溢出，以便界面始终清楚。
19. 作为老师，我想从学习记录里看出哪些题用了提示卡，以便判断学生的真实掌握情况。
20. 作为老师 / 课程方，我想经济数值集中在一份配置里，以便按课堂反馈调整而不改代码逻辑。
21. 作为维护者，我想让金币发放、心之容器、价格等规则是可单元测试的纯函数，以便调整数值不引入回归。
22. 作为维护者，我想 E2E 通过真实交互（答题、与商人对话、点击购买）验证经济线，以便和现有测试风格一致。

## 实现决策

（全部在 01 grilling 拍板后生效；以下为推荐方案，供 grilling 时逐条确认或改判）

- **经济规则集中配置**：一份纯数据配置（金币来源与数额、心之容器发放章节、道具价格与效果、难度档位参数、按章递增系数），
  与规则函数分离；规则函数是纯函数（输入：事件 + 当前状态；输出：状态增量），便于单元测试。
- **「首答正确」的判定**：依赖作答记录——同一槽位在本次抽题下的第一次确认即正确才算首答正确。
  作答记录由 `learning-records` 提供；本 effort 不自建另一套记录。
- **存档字段**：在 `learning-records/issues/01` 的 v3 存档上**追加可选字段**并提供默认值（沿用存档模块「缺省字段按初始值补齐」的做法），
  不为经济线单独升版本。形状（极简）：
  ```
  economy = {
    coins: number,
    items: { potion: number, charm: number, hintCard: number },
    heartContainers: number,      // 已获得的心之容器数；爱心上限 = 6 + heartContainers
  }
  difficulty: 'easy' | 'normal' | 'hard'   // 跟随存档（每局一个），不是设备设置
  ```
  现有存档已持久化 maxHearts；改为由 heartContainers 推导，读档时对老存档按已通关章节补发容器并重算上限。
- **HUD**：金币显示在碎片计数旁的胶囊里；爱心上限超过 8 时换为两行或「心形 + 数字」的紧凑显示（设计坐标 960 宽内不溢出）。
- **商店**：复用现有 NPC / 对话框与 DOM 浮层模式，新增一个商店浮层（模态，遵守 `accessibility` 的焦点规则）；
  商人位置推荐：每章野外的引导石碑旁（不新增地图要素，减少对地图生成器的改动）。
- **提示卡**：通过 `pyodide-sandbox/issues/01` 的题型分派扩展点对四选一 / 填空题生效：移除一个错误选项（随机、确定性地以题目 id + 槽位为种子，重开面板不变）；
  在作答记录里标记「用过提示」；BOSS 符文禁用。
- **护心符**：答错时若持有则消耗一个代替扣心，反馈文案相应改变。
- **难度档位**：新的冒险时选择（标题页），存档内保存；轻松档：小怪接触不扣心（仍有击退）；挑战档：答错扣 2 心（仍最低留 1）、小怪按章递增系数更高。
- **按章递增**：章节主题配置增加可选的小怪血量 / 速度系数与 BOSS 血量系数，默认值等于现状（保证未配置的章节行为不变）；标准档下 W6 起小幅递增。

## 测试决策

- **单元测试**（依赖 `core-unit-tests/issues/01`）：金币发放规则（首答 / 非首答 / 小怪 / BOSS）、心之容器发放与老存档补发、价格与购买校验（余额不足）、提示卡排除选项的确定性。
- **E2E 声明式 runner**：答对碎片符文后 `state()` 的金币增加；与商人对话并点击购买，金币减少、道具 +1；使用提示卡后面板选项数减 1，BOSS 符文上提示卡不可用；
  轻松档下小怪接触不扣心。runner 目前用 godmode 免伤——难度相关断言需在不开 godmode 的步骤里做，或给 seam 增加「暂停 godmode」语义动作。
- **smoke 数据层**：经济配置表结构合法（价格为正整数、档位参数齐全、每章递增系数存在或回退默认）。
- **存档迁移**：v3 存档缺 economy 字段时按默认补齐；老存档按已通关章节补发心之容器——由 `learning-records` 的迁移测试一并覆盖。

## 待决策

（即 01 grilling 的议程，每条附推荐）

1. 爱心上限成长规则——推荐「每通关两章 +1，上限 11」；备选「每章 +1」会让 HUD 拥挤且后期过于宽松。
2. 金币来源与数额——推荐首答正确 +3、非首答正确 +0、小怪 +1（掉落拾取）、BOSS +10；答错不扣金币。
3. 商店道具清单——推荐回复药水（+2 心）、护心符、提示卡；不卖「复活」（死亡惩罚本就很轻）。
4. 提示卡是否削弱学习——推荐：只排除一个错误选项、BOSS 符文禁用、讲解照常展示、作答记录标记「用过提示」。
5. 是否引入难度档位——推荐引入，「轻松」档对教学场景很重要（不擅长动作游戏的学生）。
6. 是否按章递增小怪 / BOSS——推荐标准档下 W6 起轻度递增，挑战档更明显；轻松档不递增。
7. 「猜答案零成本」是否额外处理（如答错后换一道同池题）——推荐先靠首答金币激励，不改抽题规则（改抽题会影响 ADR 外的题池消耗与 E2E 确定性）。

## 不做的事

- 装备 / 技能树 / 等级系统。
- 内购、真实货币、排行榜。
- 修改题目内容或讲解（ADR-0001）。
- 修改抽题规则（「同一槽位答对前不换题」保持不变）。
