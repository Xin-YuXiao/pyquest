# 06: 决策：答案位置偏置怎么处置

Status: ready-for-human
Type: grilling
Blocked by: 01

## 要做什么

由维护者（必要时与课程负责人一起）决定如何消除答案位置偏置。

现状：答题面板按题库原顺序显示选项，正确答案在第 1 个选项的题占 70%（175/251）。学生总选 1 就能拿到大部分碎片。

候选方案：

- **A. 运行时打乱显示顺序（推荐）**：按「符文槽 + 题目」固定种子打乱。题面一字不改，符合 ADR-0001；同一块符文石答对前每次打开顺序相同；不改存档；对未来新题自动生效。代价：E2E runner 需改为通过测试接缝读取正确答案的显示位置。
- **B. 人工逐题调整选项顺序**：这属于修改题面数据，要逐题评审；以后新题还会再次偏置，需要靠 lint 规则长期约束。
- **C. 不处理**：只在 lint 报告里展示分布。

同时决定：「正确选项是唯一最长项」占 53%（133/251）这条线索，是只报告，还是纳入 W4-W8 扩题的出题规范。

## 验收标准

- [ ] 在 Comments 记录决策（选 A/B/C 及理由），以及对「最长选项」线索的处理方式
- [ ] 若选 A：把 07 的 Status 改为 ready-for-agent
- [ ] 若选 B 或 C：相应修改或关闭 07（Status 改为 wontfix 并说明）
- [ ] 若决策涉及出题规范，在 `docs/` 中相应提纲的出题约束里补一条（或建一张后续工单）
