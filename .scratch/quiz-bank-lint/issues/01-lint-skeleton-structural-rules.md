# 01: 题库 lint 骨架与结构类规则

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

维护者运行 `npm test` 时，在 smoke 之后多一道「题库 lint」，对全部题目执行 smoke 没有覆盖的结构类规则，按规则分组输出题号与原文片段，有错误就以非零码退出。

先做 prefactor：答题面板里「章节标签 → 提示语」的映射目前写在私有方法中，把它提升为数据层导出的常量，答题面板改为读取它（行为不变）。lint 读取同一张表。

本工单的规则（全部为错误级）：

- 选项恰好 4 个，且去掉首尾空白后两两不同
- 每个章节标签在提示语表中有条目
- 题目章节标签的章号与所在题池的章号一致
- 每题恰好属于一个题池（无孤儿、无一题多池）
- BOSS 池的题都带 BOSS 标记，非 BOSS 池的题都不带
- 题干全库不重复
- 选项不含「以上都对 / 以上皆非 / 以上均 / 上述皆」等依赖选项位置的表述

另加提示级报告（不阻断）：每个题池的答案位置分布；正确选项是唯一最长项的题数；每章题量与 tier 一览。

lint 第一次运行发现的问题按类处理：界面文案缺失（目前已知「第一章 · 运算符」没有提示语）直接补上；题面问题只登记到 `.scratch/`，不改题面。

## 验收标准

- [ ] `npm test` 依次运行 smoke → 题库 lint → verify-quiz，lint 失败时 `npm test` 失败
- [ ] 提示语映射由数据层导出，答题面板行为不变（答错时显示的提示语与改动前逐条一致）
- [ ] 补上「第一章 · 运算符」的提示语（文案贴合 W1 运算符知识点：`**`、`//`、`%`、`/` 返回 float），E2E 照常通过
- [ ] 上述 7 条结构规则在当前题库上全部通过；每条规则在 Comments 里留一次「临时注入违例 → lint 报错」的验证记录
- [ ] 提示级报告打印答案位置分布（当前应为 [175, 43, 23, 10] 或与之一致的按池明细），不影响退出码
- [ ] lint 输出格式与 smoke 一致（✓ / ✗ 前缀，末尾汇总）
- [ ] README「测试」一节列出 lint 的规则清单和与 smoke 的分工
- [ ] npm run check 全绿
