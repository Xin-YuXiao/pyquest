# 04: verify-quiz 覆盖率报告与下限

Status: ready-for-agent
Type: task
Blocked by: 03

## 要做什么

维护者能看到每章有多少可执行题已经被 python 实跑校验、还差哪些，而且覆盖率只能升不能降。

把每道题归入三类之一：

- **已校验**：在校验表中
- **可执行未校验**：代码有确定输出，但还没进校验表
- **不可执行**：必须附原因，原因取值为概念题、填空题、依赖随机数、依赖外部文件或网络、依赖 CI 未安装的包之一

不可执行的原因记在一张数据表里。没有记录的题，凡是代码里有 print 且无填空，默认归为「可执行未校验」。verify-quiz 末尾按章打印三类计数，并与覆盖率下限比较：「已校验数 ÷（已校验 + 可执行未校验）」低于下限即失败。下限设为本工单完成时的实测值。

## 验收标准

- [ ] verify-quiz 输出按章的三类计数表，以及全库覆盖率
- [ ] 当前 70 道「print 且无填空但未校验」的题（v4…nm12，清单见 spec 备注）逐一归类：可执行未校验，或不可执行并写明原因
- [ ] 覆盖率下限写在配置中；人为从校验表删一题，verify-quiz 失败并说明低于下限
- [ ] README「测试」一节说明三类定义，以及新增可执行题时要做什么
- [ ] npm run check 全绿
