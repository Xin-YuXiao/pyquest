# 07: 答题面板按固定种子打乱选项显示顺序

Status: needs-info
Type: task
Blocked by: 06

## 要做什么

（前提：06 选择方案 A）学生打开符文石时，四个选项的显示顺序是按「符文槽 id + 题目 id」生成的固定排列，正确答案均匀分布在四个位置上。同一块符文石答对前，关掉再打开顺序不变；换一道题（或换一块符文石）顺序就会变。数字键 1-4 对应屏幕上的显示顺序，填空题选中后填进空槽的仍是对应选项的文本，答对与否按题库原始下标判定。存档结构不变。

测试接缝新增只读查询：当前打开题目的正确答案在第几个显示位置。E2E runner 改为读取这个值来点击，而不是直接读题目的 answer 下标。

## 验收标准

- [ ] 统计全部符文槽当前抽题的正确答案显示位置：每个位置的占比都在 15%-35% 之间（smoke 层或 lint 提示级报告中打印并断言）
- [ ] E2E 新增断言：同一符文石关闭后重开，选项显示顺序不变
- [ ] 键盘 1-4 选择、点击选择、填空题预览都按显示顺序工作（E2E 至少覆盖一道填空题）
- [ ] 答对后奖励、答错扣心的逻辑与改动前一致，11 章 E2E 全部通过
- [ ] 测试接缝的新查询写进接缝模块的文档注释
- [ ] npm run check 全绿
