# 02: 内容一致性规则与已知问题清单

Status: ready-for-agent
Type: task
Blocked by: 01

## 要做什么

题库 lint 能自动发现讲解里的三类内容不一致。已经登记、等待人工确认的问题列入「已知问题清单」，CI 保持绿色；新问题让 CI 失败；题面修好后，清单条目不删就报「过期豁免」。

三条规则：

1. **跨章引用核对**：匹配题干与讲解里的「W{N} 考过 X」「W{N} 的 X」「第 N 章考过 X」「(W{N} <题号> 考 …)」等句式，抽出章号和考点词 X。被引用章节的题池里，至少要有一道题在题干、代码或选项中出现 X（只在讲解里出现不算）。显式写了题号的，题号必须存在且属于该章。
2. **σ↔p 值换算**：匹配「kσ … p = x」「kσ（p≈x）」等写法，与正态分布单侧、双侧尾概率对照（k=1..6 内置常量）。与两者的相对偏差都超过 15% 时报错。
3. **口径对照表**：数据驱动的规则表，每条包含规范写法、禁用变体（正则）、依据和首次发现的工单。首条：有效样本量规范写法为 Neff≈N/τ（emcee τ 定义），禁用「N/(2τ)」。

已知问题清单首批 4 条，全部指向 `../../part2-landing/issues/01-quiz-explain-cross-refs.md`：st17（跨章引用 W8 percentile）、pj4（跨章引用 W9 pcov）、st9（3σ↔p）、st19（Neff 口径）。

## 验收标准

- [ ] 在当前题库上，三条规则恰好命中且只命中上述 4 处；它们因在清单内而降级为提示，lint 通过
- [ ] 从清单中删掉任意一条，lint 失败，并指出对应题号、规则和原文片段
- [ ] 在清单里加一条不会命中的假条目，lint 报「过期豁免」失败
- [ ] 跨章引用规则对 8 个现有命中句式（sg18 st3 st6 st8 st17 st19 pj4 pj11）逐一给出判定，判定表贴在 Comments，其中非问题项要说明为什么判定通过
- [ ] 口径对照表与已知问题清单都是独立数据文件，带注释说明如何新增条目
- [ ] 不修改任何题面
- [ ] npm run check 全绿
