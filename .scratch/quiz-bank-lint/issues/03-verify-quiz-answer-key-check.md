# 03: verify-quiz 答案键核对

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

## 要做什么

verify-quiz 目前只核对「python 实际输出 = 手写期望值」。增强后它还要核对期望值和正确选项的一致性：期望输出（合并空白、统一换行后）必须作为完整词元出现在正确选项文本里，且不能出现在任何错误选项里。这样可以抓住「答案下标指错了选项」「期望值和答案一起写错」这类目前完全无法发现的错误。

确实无法满足的题（例如正确选项是解释性文字、不含输出值，或输出值合法地出现在某个错误选项的说明里），进入「答案键核对豁免」表，每条写明原因。

## 验收标准

- [ ] 现有 56 道校验题全部完成答案键核对：通过，或进入豁免表并写明原因
- [ ] 若核对发现疑似答案错误，不改题面，在 `.scratch/quiz-bank-lint/issues/` 下新建工单登记（Status: ready-for-human），并加入豁免表、注明工单链接
- [ ] 人为把某道校验题的答案下标改错（本地验证后撤回），verify-quiz 失败并指出「期望输出不在正确选项中」
- [ ] 输出中区分「运行输出不符」与「答案键不符」两类失败
- [ ] Windows（GBK 控制台）与 Linux CI 上结果一致
- [ ] npm run check 全绿
