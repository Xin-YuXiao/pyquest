# 03: 伙伴样板：跟随精灵 + HUD 气泡 + 两类触发 + 开关

Status: needs-info
Type: task
Blocked by: 01, 02

## 要做什么

- 程序化像素「小望远镜」精灵（与现有程序化贴图同风格），跟随勇者、轻微漂浮，场景切换时随勇者出现。
- HUD 角落的伙伴气泡（DOM，带头像，`aria-live="polite"`），不暂停游戏，缺省 4 秒后消失；答题面板或对话框打开时排队不播，只保留最新一条。
- 伙伴调度器 + 两类触发作为样板：
  - **答错鼓励**：同一符文槽在一次答题中第 2 次答错，面板关闭时说一句鼓励（从 `wrongAgain` 候选轮换，不读取题目内容）。
  - **首次进入巢穴**：每章第一次进入巢穴时说一句。
- 冷却（缺省 20 秒）与每章次数上限；伙伴开关三档（开 / 只保留答错鼓励 / 关）写入 `story.companion`，在设置面板（若 accessibility 已落地）或标题页临时开关中切换。
- `storyInfo()` 返回最近一条气泡文本。

## 验收标准

- [ ] E2E：第一章对同一符文连续答错两次后关闭面板 → 断言气泡出现且文本属于 `wrongAgain` 候选集；切到「关」后重复 → 断言无气泡
- [ ] E2E：首次进入第一章巢穴断言气泡出现，第二次进入不再出现
- [ ] 气泡不在答题面板打开期间出现（E2E 断言面板打开时气泡元素不可见）
- [ ] 读档后伙伴开关保留
- [ ] `npm run check` 全绿
