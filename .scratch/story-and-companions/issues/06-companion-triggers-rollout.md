# 06: 伙伴触发铺开：知识点引子、可开门、低血量、闲置提示与频率控制

Status: needs-info
Type: task
Blocked by: 03

## 要做什么

在样板调度器上补齐其余触发类别（台词按 grilling 定稿）：

- **知识点引子**：本章第一次接近某类符文（碎片 / 祝福 / BOSS）时，说一句该题池的知识点预告（`poolIntro:<题池>`）。
- **可开门**：碎片集齐、封印门可解时提醒一次。
- **低血量**：爱心降到 1 颗时提醒（每章最多一次）。
- **闲置提示**：在野外 60 秒没有任何进展（碎片数、阶段、所在位置都没变）时，提示当前目标（文本与 HUD 目标行一致）。
- 全局频率控制：同一时刻只一条、类别冷却、每章上限；「只保留答错鼓励」档位下以上全部静默。

## 验收标准

- [ ] smoke：每个题池都有 `poolIntro` 台词；每类触发都有候选台词
- [ ] E2E：接近本章第一块碎片符文时断言知识点引子出现；集齐碎片后断言可开门提醒出现一次
- [ ] 闲置提示的计时在答题面板/对话框打开时暂停（单元或 E2E 断言二选一）
- [ ] 「只保留答错鼓励」档位下以上触发全部不出现（E2E 抽查一类）
- [ ] `npm run check` 全绿
