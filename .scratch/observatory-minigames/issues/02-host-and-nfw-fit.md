## 要做什么

跑通「道具 → 宿主面板 → 小游戏 → 判定 → 记录 → 接缝 → E2E」全链路：

- 新道具类型 `observatory`，由章节主题字段声明小游戏 id；通用生成器在石碑附近避让区外放置；本章未通关时按 E 只给提示不打开。
- 小游戏宿主（DOM 覆盖层）：打开时暂停场景、关闭时恢复；说明 + 「提示」按钮 + 操作区 + 结果区 + 退出按钮；Esc 退出；打开时焦点进入面板、关闭后归还。
- NFW 拟合滑块：固定 seed 生成带误差棒的模拟密度点（log-log 坐标）；ρ₀、Rₛ 两个 range 滑块（键盘方向键可微调）；实时显示 χ²、χ²/dof（三个区间不同颜色 + 文字）；完成后显示真值对比。
- 完成记录写入存档 v3 字段 `observatory`；首次完成回满爱心；保留最佳星级；「换一组数据」按钮换 seed。
- 只读接缝 `observatoryInfo()`。

## 验收标准

- [ ] smoke：同 seed 生成相同数据；真值参数 judge 为完成且三星；偏离真值 3 倍的参数 judge 为未完成；χ² 对一组 3 个点的手算值相符
- [ ] 第八章 E2E 新增 `observatory` 步骤：通关后打开 → 用 `observatoryInfo()` 的真值设置滑块 → 断言完成与星级 → 退出 → 断言 `state()` 快照含完成记录、爱心回满
- [ ] 第八章 E2E：通关前按 E 不打开面板
- [ ] 读档后完成记录与最佳星级保留
- [ ] 滑块有可读标签与当前值，判定结果以文字呈现
- [ ] `npm run check` 全绿
