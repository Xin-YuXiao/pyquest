# 代码训练场：关卡清单与概念顺序

> **状态：待助教对照讲义审核。** 训练场是编程练习，不是题库题目（ADR-0001 管的是题库），
> 但概念顺序、措辞与难度仍应与 P4A@UCAS Week 1-2 讲义一致。审核意见请写在本文末尾或对应 backlog 工单
> （`.scratch/code-the-hero/issues/01`）里。关卡数据在 `src/data/dojoLevels.js`。

## 玩法一句话

第二章森林里有一扇「代码训练场」之门（第一章通关后开放）。进门后左边是一个格子房间，右边是 Python 编辑器：
学生写真正的 Python（浏览器内的 Pyodide，Python 3.14），点「▶ 运行」，勇者按代码一步步走、跳、挥剑。
每关可能有多个**布局**（陷阱位置、小径长度、路线都不同），同一段代码要在全部布局上通过——
逼着学生写「对不同输入都成立」的代码，而不是背格子数。

## 英雄 API（按关卡逐步开放）

| API | 作用 | 首次出现 |
| --- | --- | --- |
| `move(方向)` | 走一格；方向是 `'up'` / `'down'` / `'left'` / `'right'`；撞墙、落水、踩陷阱即失败 | 第 1 关 |
| `look()` | 看面向的前方一格，返回 `'empty'` / `'wall'` / `'water'` / `'trap'` / `'shard'` / `'slime'` / `'exit'` / `'flag'`；也可 `look('up')` 指定方向 | 第 3 关 |
| `jump()` | 朝面向的方向跳过一格（能越过陷阱，不能越过墙） | 第 3 关 |
| `attack()` | 攻击面向的前方一格（打倒挡路的史莱姆） | 第 7 关 |

本关没开放的函数调用时会报「名字 xxx 没有定义」——白名单之外的 API 根本不存在于学生代码的命名空间里。

## 关卡与概念顺序

| 关 | 概念 | 标题 | 目标 | 布局数 | 参考解行数（挑战星） |
| --- | --- | --- | --- | --- | --- |
| 1 | 顺序执行、函数调用、字符串参数 | 第一步 | 走到传送门 | 1 | 6 |
| 2 | `for` + `range` | 长桥 | 走过 11 格长桥 | 1 | 2 |
| 3 | `if` / `else`、比较 `==` | 陷阱走廊 | 陷阱位置每次不同，看见陷阱就跳 | 3 | 5 |
| 4 | `while`、`!=` | 迷雾小径 | 小径长度每次不同，停在旗子上（程序结束时判定） | 3 | 2 |
| 5 | `def` 定义函数 | 台阶阵 | 「右、右、上」重复 4 次再进门 | 1 | 7 |
| 6 | 列表、`for x in 列表` | 碎片清单 | 路线写在变量 `path` 里，每次不同；收齐碎片再进门 | 3 | 2 |
| 7 | 综合：`while` + `if/elif/else` | 史莱姆巢穴 | 史莱姆 / 陷阱 / 碎片混合，三个布局 | 3 | 9 |

每关有两级提示（概念提示 → 关键语句提示），第三次点「提示」给出参考解；看过参考解后通关，
本关成绩标记「看过参考解」。个人最佳记录「代码行数 / 动作步数」，**不做排行榜**（见 `.scratch/INSPIRATION.md`）。

## 需要助教确认的地方

1. **概念顺序**：上表是否与 Week 1-2 讲义的先后一致（例如讲义里 `while` 是否在 `def` 之前）。
2. **`jump()` 的引入**：为了让第 3 关只靠 `if` 就能通关，加了一个「跳过一格」的动作；是否接受。
3. **失败即结束**：撞墙 / 落水 / 踩陷阱立即判失败（而不是原地不动）。好处是错误更显眼；代价是对新手更严格。
4. **Python 版本**：浏览器里是 Pyodide 314.0.7（Python 3.14），本机校验与 CI 用 Python 3.12；
   训练场只用最基础语法，两个版本行为一致（`scripts/verify-dojo.mjs` 用 CPython 实跑全部参考解）。

## 技术备注

- 运行时自托管：Pyodide 文件来自 npm 包（版本锁死），开发时由 vite 中间件提供，构建时复制到 `dist/pyodide/`，
  不走 CDN（离线、E2E、国内网络都可用）。首次进入训练场下载约 13.5 MB（wasm 9.6 MB），之后浏览器缓存。
- 安全：学生代码在 Web Worker 里运行，只能调用英雄 API；Worker 送回动作列表，主线程用同一个模拟器重算判定。
- 死循环：单次运行超过 4 秒即终止 Worker 并自动重建，提示「代码运行超时（是不是写了死循环？）」；
  只调用 `look()` 的死循环会在 500 次查看后被模拟器拦下。
