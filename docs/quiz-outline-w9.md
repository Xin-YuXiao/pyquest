## 第九章 · 统计圣所（贝叶斯祭司）· w9shard(26)×11 / w9lair(27)×7 / w9boss(28)×3

> grilling 决议：shard 扩为 11 题（加先验题，破 10/7/3 标准结构，仅此一章）。

| 池 | 题目知识点分配 |
| --- | --- |
| shard ×10 | 均值/中位数/众数在偏态分布中的排序（长尾分布 中位数<均值）· 泊松计数噪声 σ=√N（天体计数涨落）· 高斯 68-95-99.7 规则（1σ/2σ/3σ 对应概率）· 误差传播基本原理：独立量相加减方差相加 · 中心极限定理：大样本均值趋于正态（无论原分布）· 似然 vs 概率的区别（似然是参数的函数，不是概率分布）· χ² 统计量定义 Σ((观测−模型)/σ)² 与自由度 · 贝叶斯定理：后验 ∝ 先验 × 似然 · p 值的正确含义（P(数据\|H₀)，不是「H₀ 为真的概率」）· 置信区间正确解读（95% CI = 重复实验 95% 的区间覆盖真值，非「真值在内概率 95%」的频率派辨析，取工程共识表述） |
| lair ×7 | **泊松涨落计算**（`scipy.stats.poisson.pmf` 或 σ=√N：1000 计数源的 1σ 涨落 = 31.6；可执行）· **误差传播数值**（c=a+b，σ_c=√(σa²+σb²)：σa=3, σb=4 → σ_c=5；可执行）· **标准误**（N=25 次测量 σ=10 → 均值标准误 σ/√N=2；可执行）· **正态分位数**（`scipy.stats.norm.ppf(0.975)`≈1.96 与 95% 区间；可执行）· **χ² 拟合优度**（χ²/dof≈1 为好拟合：给 χ²=52, dof=50 → 1.04 判断；可执行）· **百分位报告**（`np.percentile(chain, [16,50,84])` 中位数±1σ 的不对称误差棒——与 W8 应用题的分工：W8 考「怎么调用」，本题考「为什么 [16,50,84] 对应 ±1σ」；可执行）· **贝叶斯更新数值例**（均匀先验 + 二项似然：抛硬币 3 正 2 反后后验众数 = 3/5；可执行） |
| boss ×3 | **MCMC 收敛诊断原理**（为什么看链混合/多链对比：马尔可夫性导致样本相关，视觉上「毛毛虫」混合好；与 W8 分工：W8 考 get_autocorr_time 用法，本题考为什么需要诊断——非独立样本使有效样本量缩水）· **模型比较与简约性**（加参数 χ² 必然下降，为什么 χ²/dof 或 AIC 更公平：惩罚额外自由度；给两模型 χ² 与参数数选优）· **新发现的 5σ 标准**（宣称发现的显著性门槛：5σ≈p<3×10⁻⁷，对应「本地显著性」；为什么需要高门槛=多重检验/look-elsewhere 效应概念） |
