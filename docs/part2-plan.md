## 第十一章 · 毕业试炼（project-driven study）

延续现有课程 Project 体系（素材：`docs/course-materials.md` §2，八个 Project）。

三类标准 workflow + 自选指引：
1. **数据拟合类**（对齐 Project-2/4：建模→拟合→参数→不确定度）
2. **模拟类**（对齐 Project-1/3：物理模型→模拟→观测效应→分析）
3. **机器学习类**（对齐 Project-5/6/7：数据→特征→训练→评估→泛化）

每类教学「选题 → 文献 → 数据 → 分析 → 验证 → 报告」标准链。
