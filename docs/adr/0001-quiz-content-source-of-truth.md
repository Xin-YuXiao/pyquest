# 1. 题库内容以 2026 版课程讲义为权威源

日期：2026-10-21
状态：已接受

## 背景

PyQuest 的 W4-W8 题库（每章 5 题）最初按 README 中从课程宣传材料总结的知识点清单编写。
2026-10 获得 P4A@UCAS 课程完整素材（`/Users/uranus/Desktop/P4A@UCAS`，含 2026 春更新的
八周讲义、作业与期末收集、八个课程 Project），进入题量充实阶段（每章 20 题）。

精读讲义后发现三处分歧：

1. 游戏 ap2（astropy units）、ap3（SkyCoord）所考内容在讲义正文中未出现（Astropy 子包
   仅目录式罗列）；
2. 游戏 dm2 的 M₂₀₀ 讲义正文未出现，讲义实际重心是 NFW 质量积分公式与 MCMC；
3. 游戏 sp4 使用小写 `comm.bcast`（对象广播），讲义通篇使用大写 `comm.Bcast`
   （数组缓冲区广播）。

## 决策

题库内容以 **2026 版讲义为唯一权威源**：超纲题（ap2/ap3/dm2）替换为讲义内知识点题，
API 写法跟随讲义（大写 `Bcast`）。README 原知识点清单仅作粗略索引。

## 后果

- 学生按周玩通时遇到的 API 与讲义完全一致，不会出现"游戏教了课堂没讲/写法不同"的困惑；
- astropy units/SkyCoord、M₂₀₀ 等天文常识从 W4-W8 题库消失（它们仍是合理的天文知识，
  未来若扩充题库可引入，但需以其他素材源明确标注）；
- 讲义更新（2027 春等）时需重新比对，本题库随之维护。

## 备选方案

- 保留超纲题（被否）：与"学生按周玩通"的验收标准冲突；
- 超纲题标注"拓展"并存（被否）：每章仅 20 题，拓展题挤占讲义核心知识点的空间。
